## 提案する施策 (3 つ)

### 1. 記録漏れを、OS の入口で拾う

アプリを開く前から記録が始まり、撮り忘れも後から拾えるようにする。

- **撮る入口**: ロック画面・コントロール・アクションボタンから HINAMI のカメラを開く (決めたこと)
- **食事中**: 1 品目を残したら、その食事がまとまっている間だけ、ロック画面に「いまの食事」(店名と写真 1 枚) を Live Activity で出し、2 品目からはそこから撮る
- **撮り忘れ**: 標準のカメラで撮って入れ忘れた分は、Apple の「ジャーナルの提案」と、画面に埋め込む写真の選択 (許可が要らない) で拾う。候補を作るのは OS で、HINAMI には利用者が選んだものしか渡らない
- **なぜ**: 記録漏れは、レビューで PHASE 1 を落とす最大の理由とされた。以前「HINAMI が端末の写真を走査する」案は怖いので採らなかったが、この形なら HINAMI は写真を見に行かない
- **事例**: Locket は、ロック画面に出す毎週の投稿で、アクティブの 25% 超が毎週投稿する (自社)。Day One はジャーナルの提案に対応している
- **前提とリスク**: ロック画面のカメラは Swift で書く別の部品で、位置が取れるかは未確認。ジャーナルの提案は食に絞れず、食の記録アプリに使う許可が出るかも未確認。Live Activity は同席者にも見えるので、止められるようにする

### 2. 写真を外に出さない AI

種類の判定、ラベルの読み取り、店の推定を、できるだけ端末の中で行う。

- **判定**: 端末のモデル (Apple の Foundation Models。iOS 27 で画像を受けられる) と文字認識で、種類の一覧から選ばせる。足りないときだけ Apple のサーバー (Private Cloud Compute)、それでも足りないときだけ同意を取って外部の AI に送る
- **酒のラベル**: 端末で文字を拾い、銘柄・蔵・種別に整えて、メモの候補にする。縦書きや毛筆は弱いので、外部に回すかを比べる
- **店**: MapKit で、撮った位置の近くを飲食に絞って探し、店の ID (Place ID) を持つ。期限なく保存でき、サーバーや姉妹アプリと同じ ID を使える
- **その先**: 「渋谷で前においしかった鮨」と聞くと、言葉を種類・地域・期間の絞り込みに直して、自分の記録を返す
- **なぜ**: 写真を外に出さないのが既定になり、外部の AI への送信の同意 (審査ガイドライン 5.1.2(i)) や海外への送信の論点が小さくなる。電波がなくても種類が付き、推論の費用もかからない。Google Places の規約と費用の課題も避けられる
- **前提とリスク**: iOS 27 と Apple Intelligence が動く端末 (iPhone 15 Pro 以降) が要る。動かない端末では外部の AI に頼る。端末のモデルが食をどこまで当てられるか、日本の飲食店を MapKit がどこまで持っているかは未検証。今想定している Jev を見直すことになる

### 3. 記録が返ってくる: 「前回のこの店」と、暦の帳面

記録を求めるのではなく、記録を返す。HINAMI (日次) の名前と「夜の帳面」の世界観にそのまま合う。

- **その場で返す**: 店が決まったら、確認カードや食事の詳細で「前回ここで食べたもの」と、その種類の自分の順位を見せる。次に何を頼むかに効く
- **思い出をそっと出す**: ホームとウィジェットに「1 年前の今日」を 1 件出す。通知は既定で出さない。食事ごと・期間ごとに「思い出に出さない」を持つ
- **暦の節目の帳面**: 週 (日曜の夜) と月の帳面に、その期間の皿を並べる。件数、空白の日、目標は出さない。記録がない週は何も出さない。年の帳面 (年間ふりかえり) はその集大成で、縦長の 1 枚ずつにし、全員に無料で見せ、1 枚ごとに出すものを選べる
- **なぜ**: 人は日常を後で見返す楽しさを低く見積もる (Zhang ら 2014)。良い思い出はストレスを和らげる (Speer & Delgado 2017)。Spotify Wrapped、Beli Plated、Letterboxd のふりかえりが広まった。週の帳面は、PHASE 1 の 3〜4 週目に実績が出にくくなる問題も補う
- **前提とリスク**: つらい思い出が出ることがある。週の帳面が「今週も残さなきゃ」という義務にならないよう、量に触れず、通知で出さない。年の帳面を端末に画像で保存すると外に広まるので、「外への共有は最初の版に入れない」との関係を決める
