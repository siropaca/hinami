## 事業

1. コンセプト「自分のための、育つ食と酒の記録帳」で進めてよいか
2. 対象ユーザー「食と酒にこだわる、少し余裕のある大人」で合っているか
3. 外食と手料理の比重 (手料理を同じ主役にするか)
4. 公開時の最初の図鑑を、料理 (ラーメン等) と地酒のどちらから始めるか
5. 見せる相手。不特定多数は前提にしないが、身内や知り合いなど気の知れた人には見せる前提にするか (作り手は「そうかもしれない」)。決まったら concept.md の「人に見せる食レビューではなく」と、公開範囲の既定 (自分だけ) を見直す

## 技術 (未確認)

- 画像判定の AI は TypeSafe AI の Jev を想定 (要確認)。端末内では動かず写真を外部に送るため、送る前に位置情報を消す。画像入力はまだ実験扱い。電波のない場所では判定を後回しにする。種類 (ラーメン、日本酒など) の判定は、Jev の画像認識で足りると作り手は見ている
- 実績を運営の管理画面から足すには、実績の定義をアプリの外 (サーバー) に置く必要がある。サーバーの構成はまだ決めていない
- Web のプロトタイプでは、iOS Safari が写真の位置情報を消す場合がある ([WebKit bug 257534](https://bugs.webkit.org/show_bug.cgi?id=257534))。写真から店を出す流れは Web では試せない恐れがある

## デザイン

1. 世界観「夜の帳面」で進めてよいか
2. 写真は自分の写真で作り込むか、生成した写真で仮に組むか
3. 明るい (生成り背景) 版も用意するか、墨色 1 本に絞るか
4. 残りの画面 (地図、年間ふりかえり、つながる) を同じ世界観で起こす
