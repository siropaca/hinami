操作は OS のガラス、紙面は HINAMI。
2 つの層を混ぜない

操作の層 · Liquid Glass

タブバー、＋、トースト、シート、ナビの丸いボタン。丸く、ガラスに色を足さない。色を付けるのは主な操作の ＋ だけ (金)

紙面の層 · HINAMI

写真、日付の欄、罫、品名、印。角を立て、ガラスを使わない

タブバーは OS のもの (expo-router の NativeTabs)、ガラスは expo-glass-effect、アイコンは SF Symbols の細め。出典: Apple「Meet Liquid Glass」(WWDC25)、Expo「GlassEffect」

HINAMI デザインコンセプト

Apple は、ガラスを操作の層に限り、一覧などの中身には使わないよう勧めている。OS の部品をそのまま使えば、作る手間も減り、OS が変わっても古びにくい。ガラスには下の写真の色が透けるが、それは OS の仕様で、HINAMI からは色を足さない。
