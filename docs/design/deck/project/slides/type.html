しっぽり明朝をやめる理由: 1 ウェイトで約 8.7MB と重く、カナが小さく字間が空くため、カタカナの品名 (コーヒー、ワイン) が間延びする。数字はライニング数字で組む。このスライドと画面イメージでは、ヒラギノの代わりに Noto の書体を使っている

HINAMI デザインコンセプト

OS の書体にすると、アプリの容量が増えず、文字の大きさの設定 (Dynamic Type) にも素直に従う。HINAMI らしさは、明朝の品名、大きな欧文の日付、印で出す。
