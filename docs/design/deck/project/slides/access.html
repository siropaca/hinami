ACCESSIBILITY

大きな文字、読み上げ、動きを減らす設定でも、帳面のまま使える

設定どうする
文字を大きく本文・品名・補足は大きくする。大きな日付と順位には上限をかける。いちばん大きい段階では、カレンダーを日ごとの一覧に替える
読み上げ印は飾りとして読まず、名前と条件を 1 つの言葉で読む。トーストは自動で閉じない
コントラストを上げる色を 4 通り (明・暗 × ふつう・高コントラスト) で持ち、罫と面を濃くする
動きを減らす印を押す動きと、実績の入れ替えをやめ、フェードだけにする
色だけで伝えない実績の進み具合は、朱の輪と「1 / 2 回」の文字の両方で出す

HINAMI デザインコンセプト

レビューで、印の中の小さな文字と、時間で消えるトーストが問題に挙がった。どちらも、情報を文字で出し、自動で消さない形で解く。色の 4 通りは React Native の DynamicColorIOS で持てる。
