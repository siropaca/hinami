# デザインコンセプト (スライド)

HINAMI のデザインの方向性を、スライドにまとめたもの。2026-11-28 に、前の案「夜の帳面」([`../../references/slides/design-deck/`](../../references/slides/design-deck/)) を、コンセプトの変更 (口にするものなら何でも、種類に偏らせない) に合わせて組み直す提案として作った。

- オンライン版 (claude.ai のアーティファクト。所有者のみ閲覧可): https://claude.ai/artifact/MvaKRnvLeE6RbQ3QuYKfQs
- 中身の正は [`../direction.md`](../direction.md)。決まりが変わったら、スライドも直す
- 画面イメージの元は [`../screens/index.html`](../screens/index.html)

## ファイル

| パス                       | 中身                                                                      |
| -------------------------- | ------------------------------------------------------------------------- |
| `project/deck.json`        | タイトル、スライドの順番、章立て、書体                                    |
| `project/deck.css`         | 全スライド共通のスタイル                                                  |
| `project/slides/<id>.html` | 1 枚 1 ファイル。1920×1080 のキャンバス                                   |
| `img/`                     | スライドに載せた画面イメージ (`../screens/index.html` から書き出したもの) |

スライドの画像は、アーティファクトに上げた画像 (`/_blob/...`) を指している。画面を直したら、`img/` を書き出し直し、アーティファクトに上げ直して差し替える。

## 画面イメージを書き出す

`../screens/index.html` をブラウザで開くと、全画面を並べて見られる。画像にするときは、Playwright で `.shot` の要素ごとに撮る (倍率 2)。写真は Unsplash の仮置きで、ネットにつながっているときだけ出る。
