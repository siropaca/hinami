# デザインコンセプト (スライド)

HINAMI のデザインの方向性を、スライドにまとめたもの。2026-11-28 に、前の案「夜の帳面」([`../../references/slides/design-deck/`](../../references/slides/design-deck/)) を、コンセプトの変更 (口にするものなら何でも、種類に偏らせない) に合わせて組み直す提案として作り、同じ日に作り手の判断 (世界観「日々の帳面」、明暗 2 つの紙面、金を残す、OS のヒラギノ、写真は仮置き、ロゴ、トークン、ブランドの金) を反映した。

- オンライン版 (claude.ai のアーティファクト。所有者のみ閲覧可): https://claude.ai/artifact/MvaKRnvLeE6RbQ3QuYKfQs
- スライドは写し。中身の正は [`../README.md`](../README.md) から辿る文書 (方向性、トークン、ロゴ)。決まりが変わったら、スライドも直す
- 画面イメージの元は [`../screens/index.html`](../screens/index.html)

## ファイル

| パス                       | 中身                                                            |
| -------------------------- | --------------------------------------------------------------- |
| `project/deck.json`        | タイトル、スライドの順番、章立て、書体                          |
| `project/deck.css`         | 全スライド共通のスタイル                                        |
| `project/slides/<id>.html` | 1 枚 1 ファイル。1920×1080 のキャンバス                         |
| `img/`                     | スライドに載せた画像 (画面イメージ、印、ロゴ)                   |
| `blobs.json`               | アーティファクトに上げた画像の番号と、`img/` のファイル名の対応 |

スライドの画像は、アーティファクトに上げた画像 (`/_blob/...`) を指している。番号とファイルの対応は `blobs.json` にある。画面やロゴを直したら、[`../tools/`](../tools/README.md) の道具で `img/` を書き出し直し、アーティファクトに上げ直して差し替える。

## 画面イメージを書き出す

`../screens/index.html` をブラウザで開くと、全画面を並べて見られる。画像にする手順は [`../tools/README.md`](../tools/README.md)。写真は Unsplash の仮置きで、ネットにつながっているときだけ出る。
