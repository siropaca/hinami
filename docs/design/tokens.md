# デザイントークン

> **状態: 定義を決めた (2026-11-28)**。`packages/` にコードとして置くのは、アプリを作り始めるとき (作り手の判断)。値は今の案で、実機で見て詰める。

世界観と色・書体の考え方は [`direction.md`](direction.md)、ロゴは [`logo/README.md`](logo/README.md)。ここでは、それを実装で使う名前と値に落とす。値の正はここで、ほかの文書や画面イメージと食い違ったら、ここに合わせる。

## 方針

- 名前は役割で付ける (「金」ではなく「操作と順位の色」が分かる名前)。コードの名前は英語、説明は日本語
- 色は 4 通りで持つ: 明るい紙面、暗い紙面、それぞれの「コントラストを上げる」設定
- 文字は iOS の Dynamic Type の段に乗せ、利用者の文字の大きさの設定に従う。大きな日付と順位だけ、大きくなりすぎないよう上限をかける
- 操作の層 (タブバー、ボタン、シート、トースト) は OS の部品とガラスに任せ、トークンを作らない。トークンは紙面の層 (写真、罫、文字、印) のためのもの

比は、紙に対するコントラスト。

| `ink`          | 文字                                                            | `#16130F`  | `#F2EDE4` | `#0E0C09`              | `#FFFBF4`            |

| `rule`         | 罫 (区切り線)                                                   | `#D6CEC0`  | `#3A342C` | `#8C8375`              | `#6B6255`            |

| 名前           | 明るい紙面 | 暗い紙面 | 明るい・高コントラスト | 暗い・高コントラスト |
| -------------- | ---------- | -------- | ---------------------- | -------------------- |
| `ink`          | 16.0:1     | 15.9:1   | 16.9:1                 | 18.0:1               |
| `inkSecondary` | 5.1:1      | 6.7:1    | 7.7:1                  | 9.9:1                |
| `rule`         | 飾り       | 飾り     | 3.2:1                  | 3.1:1                |
| `gold`         | 3.7:1      | 6.8:1    | 4.6:1                  | 9.0:1                |
| `shu`          | 5.5:1      | 5.3:1    | 7.1:1                  | 6.7:1                |

- 明るい紙面の `gold` (3.7:1) は、大きな文字と記号の基準 (3:1) を満たし、小さな文字の基準 (4.5:1) には届かない。作り手の判断で明るさを優先し、高コントラストの設定で `#7E6A2C` に戻す ([`direction.md`](direction.md) の「色」)
- 高コントラストの設定では、罫を濃くして区切りが見えるようにし、面も少し濃くする
- 写真には色を足さない。写真の上に文字を置くとき (カメラなど) は、OS のガラスか、下を暗くするグラデーションを使う

## ブランドの金

アプリの外 (App Store、SNS、印刷物、名刺) で使う金。2026-11-28 に決めた。

| 名前                 | 値        | 使う所                               |
| -------------------- | --------- | ------------------------------------ |
| `brandGold` (代表色) | `#B8995F` | アイコンの金。墨の地や写真の上のロゴ |
| `brandGoldOnLight`   | `#8F7832` | 白や生成りの地の上のロゴ             |

- 代表色はアイコンの金にそろえる。いちばん多くの人が見るブランドの姿がアイコンのため
- 明るい地では代表色が薄く見える (白の上で 2.7:1) ので、アプリの中と同じ考えで `#8F7832` に替える
- 印刷の目安 (CMYK): `#B8995F` は C0 M17 Y48 K28、`#8F7832` は C0 M16 Y65 K44。画面の色からの単純な換算なので、刷るときは印刷所の色見本で合わせる。高級感を出したい刷り物 (名刺、ショップカード) は、金の特色インキか箔押しにする
- 1 色に固定する案は採らなかった ([`history.md`](history.md) の「ブランドの金」)

## 動きと振動

3 つの場面だけに当てる ([`direction.md`](direction.md) の「手触り」)。

| 場面         | 動き                                                     | 振動 (Expo Haptics)   |
| ------------ | -------------------------------------------------------- | --------------------- |
| 残す         | 日付印: 1.15 倍から 1 倍へ、0.26 秒、ばね (戻りは小さく) | `impactAsync(Light)`  |
| 実績を解除   | 朱の印: 同じ押す動き                                     | `impactAsync(Medium)` |
| 順位が決まる | 番号: 幅から 1 つの数字へ、ばね (0.35 秒前後)            | `selectionAsync()`    |

- 動きを減らす設定では、押す動きを 0.2 秒のフェードに替える
- 音は既定でオフ

## アイコン (記号)

- SF Symbols を使う。太さは細め (Light)。大きさは OS の決まりに従う
- 独自の記号は作らない (印とロゴを除く)

## packages に置くときの形 (今の案)

アプリを作り始めるときに決める。今の案は次のとおり。

- `packages/design-tokens/` に置き、web とネイティブで共有する ([ADR-0001](../adr/0001-monorepo-and-stack.md))
- 色は 4 通りを持つオブジェクトにし、ネイティブでは `DynamicColorIOS` で明暗と高コントラストを切り替える
- 文字の段は、Dynamic Type の段の名前と、上限 (`maxFontSizeMultiplier`) を持つ

## 決めていないこと

- 値は今の案。実機の明るい場所と暗い場所で、罫の濃さ、面の色、金の明るさを見て詰める
- 明朝の太さ (W3 のままか、品名の一部を W6 にするか) は、実機で見て決める ([`direction.md`](direction.md) の「決めていないこと」)
- 印のかすれの画像の作り方と、`packages/` に置くときの形は、アプリを作り始めるときに決める
