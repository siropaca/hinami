## シンボル「皿と箸」

上から見た皿を、1 膳の箸が横切る形。毎日の食卓を 1 つの形にする。丸い皿を箸が横に渡るので、「日」の形も感じさせる。

| 決まり              | 中身                                                                                                            |
| ------------------- | --------------------------------------------------------------------------------------------------------------- |
| 箸の向き            | 右手で取る置き方。箸先が左、持ち手が右 (作り手の判断)                                                           |
| 傾き                | 右上がりに 24 度。少し斜めにして動きを出す (作り手の判断)                                                       |
| 箸の位置            | 左下から入り、皿を横切って右上へ抜ける。箸先は左下の縁から少し外へ、持ち手は右上の縁から外へ出す (作り手の判断) |
| 皿                  | 外の縁と内の縁の 2 本の線                                                                                       |
| 線の太さ (100 単位) | 2 段。外の縁と箸の持ち手が 4.2 と 4.0、内の縁が 2.0。箸先は 1.8                                                 |
| 2 本の箸            | 隙間は 3.0 で一定。小さくしても 1 膳に見えるようにする                                                          |
| 重なり              | 箸が皿の線をまたぐ所に、2.0 の隙間を切る。箸が皿の上に乗って見えるようにする                                    |
| 簡略版              | 16〜32px で使う。内の縁と重なりの隙間を省き、線を太くする (`symbol-simple-*.svg`)                               |

## テキストロゴ

- Cormorant Garamond Medium の HINAMI を輪郭にした。書体が入っていない環境でも同じ形で出る
- 字間は 0.19em。斜めの画で空いて見える N と A、A と M の間は詰める
- アプリの中の見出しのロゴも、この形と色を使う

## セット

| セット | 組み方                                                                                       |
| ------ | -------------------------------------------------------------------------------------------- |
| 横組み | シンボルが左、テキストロゴが右。皿の中心を文字の高さの中央にそろえ、持ち手が文字のほうへ向く |
| 縦組み | シンボルが上、テキストロゴが下。皿と箸の重心で、左右の中心をそろえる                         |

## 色

| ファイル名の末尾 | 色               | 使う背景                    |
| ---------------- | ---------------- | --------------------------- |
| `-gold`          | 金 `#8F7832`     | 明るい紙面 (生成り)         |
| `-gold-dark`     | 金 `#B8995F`     | 暗い紙面 (墨)               |
| `-ink`           | 墨 `#16130F`     | 明るい背景で 1 色にするとき |
| `-kinari`        | 生成り `#F2EDE4` | 暗い背景で 1 色にするとき   |

- 紙面ごとに金の明るさを変える (作り手の判断。[`../direction.md`](../direction.md) の「色」)
- 朱はロゴに使わない (朱は印だけ)

## アプリのアイコン

| ファイル              | 中身                                                                  |
| --------------------- | --------------------------------------------------------------------- |
| `app-icon.svg`        | 1024 の正方形。墨の地に、金 (`#B8995F`) のシンボル。角は iOS が丸める |
| `app-icon-tinted.svg` | 色付きの表示の元。灰色 1 色。OS が色を付ける                          |

- 暗い表示の版は、標準と同じ (もともと墨の地)
- iOS 26 以降の層のアイコンは、Icon Composer で墨の地・皿・箸を別の層にする。重なりの隙間は、層の奥行きに任せる
- SVG は隙間をマスクで切っている。ほかの道具に取り込むときは、輪郭に変換してから使う

## 余白と最小の大きさ

- 周りの余白は、皿の直径の 1/4 以上を空ける
- 最小の大きさ: シンボルは 16px (簡略版)、テキストロゴは幅 72px、横組みは幅 120px

## してはいけないこと

- 箸の向き (箸先が左) と角度を変える
- 金にグラデーションや影を付ける (iOS のガラスが光を足す)
- テキストロゴの字間を変える、別の書体で打ち直す

## 作り直す

ロゴのファイルは [`build.py`](build.py) で書き出している。形や字間を直すときは、ここを直して書き出し直す。スライドに載せる画像の撮り直しは [`../tools/README.md`](../tools/README.md)。

```bash
python3 -m venv .venv && .venv/bin/pip install fonttools
```

```bash
.venv/bin/python build.py docs/design/logo CormorantGaramond-Medium.ttf
```

書体のファイルは Google Fonts の Cormorant Garamond (Medium) を使う。`.venv` と書体のファイルはリポジトリに入れない。

## 渡し箸について

器の上に箸を渡す「渡し箸」は、和食の作法で避ける「嫌い箸」の 1 つ。このロゴは皿の左右に箸が渡るので、渡し箸に見えるとレビューで指摘された。箸先を皿の上で止める形 (皿に乗せる) も作ったが、作り手が、下から入って皿を突き抜ける形を選んだ (2026-11-28)。限定テストで、食にこだわる人の受け取り方を確かめる。

## 確かめること

- 商標: 出願の前に、J-PlatPat で図形 (円と箸) を区分 9・42 で調べる。出願は、HINAMI の文字と組み合わせた形を基本にする ([`../../open-questions.md`](../../open-questions.md) の「サービス名の確認」)
- 16px で「∅ / Ø」の記号に見えないか、実機で確かめる
- 和食に寄って見えないか、渡し箸に見えて気になるか。限定テストで、ワインやカフェ、パンが好きな人と、和食にこだわる人の両方に聞く

## 検討して外した案

別の目のレビューで指摘を受けたものと、作り手が選ばなかったもの。

| 案             | 外した理由                                                             |
| -------------- | ---------------------------------------------------------------------- |
| 丸に日         | 記号の ㊐ (日曜) や家紋 (丸に一文字) に近く、商標の識別力が弱い        |
| 器と日         | ごはん茶碗の絵文字や丼のアイコンに見え、和食と大衆食に寄る             |
| 皿と箸を横に   | 箸が皿の左右に突き抜けて、土星に見える                                 |
| 塗りの皿       | 皿が塗りの円になり、棒付きの飴に見える                                 |
| 皿に乗せる     | 箸先を皿の上で止め、渡し箸に見えない形。作り手が、突き抜ける形を選んだ |
| 匙、一皿と一杯 | ラケットや虫眼鏡、カメラに見える                                       |
