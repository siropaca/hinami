## 2026-11-26 前の案「夜の帳面」

スライドは [`../references/slides/design-deck/`](../references/slides/design-deck/) (`view.html` をブラウザで開く)。

sake flight が「旅」(パスポート、搭乗券) で世界観をつくったのに対し、HINAMI は名前どおり「暦」でつくる、とした案。

- 原則: 写真が主役、色を絞る、日次のモチーフ
- 色: 墨 `#16130F` (背景)、生成り `#F2EDE4` (文字・紙面)、金 `#B8995F` (操作と順位だけ)、朱 `#A23F2E` (印だけ)
- 書体: しっぽり明朝 (見出し・品名)、Cormorant Garamond (日付・数字・ロゴ)、Noto Sans JP (本文・操作)。すべて Google Fonts
- モチーフ: 日付印、帳面の罫線、朱印 (実績を御朱印帳のように埋める)
- 起こした画面: ホーム、記録する、食事の詳細、比べる、ランキング、実績 (当時は「図鑑・ラリー」)

## 2026-11-28 「日々の帳面」に組み直す

コンセプトが「口にするものなら何でも記録できる、種類に偏らせない」に広がり、夜と酒に寄った見た目が合わなくなった。帳面の比喩と「写真が主役」は残し、偏って見える部分を変えた。

| 前の案の要素               | どう見えたか                                     | どうしたか                       |
| -------------------------- | ------------------------------------------------ | -------------------------------- |
| 世界観の名前「夜の帳面」   | 使う時間帯を夜に決めている                       | 時間帯を選ばない「日々の帳面」   |
| 墨の背景だけ               | 夜と酒の場に寄って見える。明るい場所では見づらい | 明暗 2 つの紙面                  |
| 地酒図鑑 (都道府県の朱印)  | 日本酒の人だけの楽しみに見える                   | 種類は丸、店は角、土地は小判の印 |
| 見本が鮨と日本酒           | 作り手の好みが前提に見える                       | 見本の写真を種類でならす         |
| しっぽり明朝・Noto Sans JP | 容量が重く、カタカナの品名が間延びする           | OS のヒラギノ                    |

### 採らなかった案

| 案                                    | 理由                                                                                                                                                       |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「夜の帳面」のまま                    | 夜と酒に寄って見え、朝のカフェやパン、酒を飲まない人に「自分のためのアプリ」と映りにくい                                                                   |
| 墨 1 本に絞る                         | 夜と酒に寄って見えやすく、明るい場所では見づらい                                                                                                           |
| 金をやめ、墨・生成り・朱の 3 つにする | デザイナーの提案。金は生成りの上で 2.34:1 しかないためだった。作り手が、一休のように白い背景でも金で高級感を出したいと判断し、濃さを紙面ごとに変えて残した |
| 名前の候補「一日一頁」「食の暦」      | 「日々の帳面」のほうが、名前「日次」とまっすぐつながる                                                                                                     |
| しっぽり明朝を同梱する                | 1 ウェイトで約 8.7MB と重い。カナが小さく字間が空くため、カタカナの品名が間延びする (詰めの情報も持たない)                                                 |

- 明るい紙面の金は、はじめ小さな文字の基準 (4.5:1) を満たす `#7E6A2C` にしたが、作り手が少し明るくしたいと判断し、`#8F7832` にした。`#7E6A2C` は高コントラストの設定に回した

### レビュー

別の目のレビューを 1 回通し、指摘を反映した。

- 利用者役 5 人 (酒を飲まないカフェとパン好き、ワイン、ウイスキー、日本酒、子育て中の家ごはん): 偏りがカフェとパンに移っていた → 見本の写真をならした。帳面らしさが印に頼っていた → 一覧を帳簿の組み方にした。印が単調 → 形を 3 つに分けた
- iOS のデザインとアクセシビリティの専門家: 印の中の小さな文字に情報があった → 文字で出し直した。暗い紙面の朱が小さな文字に足りない → `#D6694F` に上げた。カメラの左下に最新の写真を出していた (写真を見に行かない決まりに反する) → アイコンにした。＋ だけが不透明 → 色を付けたガラスにした。しっぽり明朝の容量と組み → OS の明朝にした

## 2026-11-28 ロゴ「皿と箸」

はじめは「丸に日」と「器と日」を作った。作り手が「もっと食を連想させる形も見たい」とし、皿と箸の形に移った。そこから作り手の判断で、次の順に詰めた。

1. 皿に箸が乗って「日」を表す形を採る。少し斜めにする
2. 箸は右手で取る向き (箸先が左、持ち手が右)
3. 箸は下から入り、皿を突き抜ける
4. アイコンでは、皿を真ん中に置く (外枠で中央にそろえると、皿が左に寄って見えた)
5. 箸先と持ち手の、皿からのはみ出しをそろえる

### 検討して外した案

別の目のレビューで指摘を受けたものと、作り手が選ばなかったもの。

| 案             | 外した理由                                                             |
| -------------- | ---------------------------------------------------------------------- |
| 丸に日         | 記号の ㊐ (日曜) や家紋 (丸に一文字) に近く、商標の識別力が弱い        |
| 器と日         | ごはん茶碗の絵文字や丼のアイコンに見え、和食と大衆食に寄る             |
| 皿と箸を横に   | 箸が皿の左右に突き抜けて、土星に見える                                 |
| 塗りの皿       | 皿が塗りの円になり、棒付きの飴に見える                                 |
| 皿に乗せる     | 箸先を皿の上で止め、渡し箸に見えない形。作り手が、突き抜ける形を選んだ |
| 匙、一皿と一杯 | ラケットや虫眼鏡、カメラに見える                                       |

外した形の画像は、スライドの「検討して外した形」([`deck/`](deck/README.md)) にある。
