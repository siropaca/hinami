# デザインの方向性

> **状態: 決めた (2026-11-28、作り手の判断)**。前の案「夜の帳面」(2026-11-26) を、コンセプトの変更 (口にするものなら何でも記録できる、種類に偏らせない) に合わせて、世界観「日々の帳面」に組み直した。経緯と外した案は [`history.md`](history.md)。

ここには考え方と理由を書く。値は [`tokens.md`](tokens.md)、ロゴは [`logo/`](logo/README.md)、資料の地図は [`README.md`](README.md)。

## 必ず守る志向

- 写真などを使って「大人」「高級感」を演出する
- シンプルで洗練された印象。ただしオリジナリティがある
- 参考: 今はもうないアプリ「sake flight」。世界観があってかっこいい ([事例ページ](https://tacto-inc.com/work01_detail.html))
- 参考: 一休.com。白い背景でも、金を使って高級感を出している (作り手の指摘。2026-11-28)

## 3 つの原則

1. **写真が主役、紙面は静か**: 紙面の色は墨・生成り・金・朱の 4 つだけ。ほかの色は写真に任せる。枠や影で囲まず、余白と細い罫で区切る
2. **帳面の作法を、全画面に通す**: 名前「日次」から引いた 1 つの比喩でアプリ全体をつくる (sake flight に学ぶのは、比喩そのものではなく、1 つの比喩を全体に通すこと)
3. **朝の一杯も、夜の一皿も**: 明るい紙面と暗い紙面を同じ質で作る。どの種類の写真も、同じ枠と同じ重さで並べる。見本の写真も種類でならす

## 帳面の作法

| 作法           | 形                                                                                                  | どこで                      |
| -------------- | --------------------------------------------------------------------------------------------------- | --------------------------- |
| 日付の欄       | 左に大きな日付、右に記録。罫で 1 行ずつ (帳簿の組み方)                                              | ホーム、食事の詳細          |
| 日付印         | 残したとき、その日の欄に墨の印を押す。形は帳簿に押す日付印 (データ印: 名前・日付の帯・下の段)       | ホーム                      |
| 朱印           | 実績は朱の印。種類は丸、店は角、土地と場面は小判。まだの実績も同じ形で、朱の輪で進み具合を出す      | 実績のタブ、トースト        |
| 余白の書き込み | 記録から読み取った好みは、左に細い線を引いた注釈にする。AI を光らせず、出どころは「記録から」と書く | 好みのことば (置き場は未定) |
| 綴じる         | 1 年の帳面を綴じて見返す                                                                            | 年間ふりかえり (あとで)     |

- 印は飾り。名前・回数・日付は、印の下に文字で出す (大きな文字と読み上げのため)
- 印は写真に重ねない (写真に手を加えない)

## 明暗

- 明るい紙面 (生成り) と暗い紙面 (墨) を同じ質で作り、OS の設定に従って切り替える。色の名前は同じで、値だけを入れ替える
- 「暗い = 夜と酒、明るい = 朝とカフェ」にしない。見本も同じ中身で見せる
- カメラは、どちらでもいつも暗い (写真を見る面として、OS のカメラと同じ)

## 色

| 色     | 明るい紙面 | 暗い紙面 | 用途                                                 |
| ------ | ---------- | -------- | ---------------------------------------------------- |
| 生成り | 紙         | 文字     | 背景と文字。面・薄墨・罫は、墨と生成りの間の色で作る |
| 墨     | 文字       | 紙       | 同上                                                 |
| 金     | 操作と順位 | 同じ     | ロゴ、選んだ絞り込みとタブ、＋、リンク、順位の数字   |
| 朱     | 印だけ     | 同じ     | 実績の印                                             |

- 値とコントラスト比は [`tokens.md`](tokens.md) の「色」
- 金は本文に使わない。金の塗りの上の文字は、紙の色にする
- 金は一休.comに学ぶ ([デザインガイドライン](https://www.ikyu.co.jp/design_guideline/color))。一休.comレストランの主の色は `#AF9B65` (銀の混ざった、時を経た金箔のような金) で、ロゴ・アイコン・絞り込みの枠と塗りに使い、本文には使っていない。1 位とゴールド会員の色は別に持つ。HINAMI の生成りの上では `#AF9B65` が 2.36:1 になるため、同じ考えのまま濃くした
- 金の明るさは紙面ごとに変える。明るい紙面の金は、大きな文字・アイコン・枠の基準 (3:1) を満たし、小さな文字の基準 (4.5:1) には届かない明るさにした (作り手の判断)。その分、コントラストを上げる設定では濃くする
- アプリの外で使うブランドの金は、アイコンの金を代表色にし、明るい地では明るい紙面の金に替える ([`tokens.md`](tokens.md) の「ブランドの金」)

## 書体

| 書体                      | 用途                   | 備考                                      |
| ------------------------- | ---------------------- | ----------------------------------------- |
| ヒラギノ明朝 (OS 内蔵)    | 見出し・品名・店名     | 同梱しない                                |
| Cormorant Garamond (同梱) | 大きな日付・順位・ロゴ | 28pt 以上だけ。数字はライニング数字で組む |
| ヒラギノ角ゴ・SF Pro (OS) | 本文・操作・小さな数字 | Dynamic Type に従う                       |

- OS の書体にすると、アプリの容量が増えず、文字の大きさの設定に素直に従う。HINAMI らしさは、明朝の品名、大きな欧文の日付、印で出す
- 大きな日付と順位は、文字の大きさの設定に上限をかける。段と大きさは [`tokens.md`](tokens.md) の「文字の段」

## 写真

- 比率は 4:5 (一覧・詳細) と 1:1 (比べる・カレンダー・順位) の 2 つ
- 皿が真ん中に来るよう、自動で切り出す (Vision の注目領域)。写真そのものには手を加えない
- 写真の角はほとんど立てる (印刷した写真のように)。丸いガラスの操作と分ける
- 画面イメージの写真は仮置き (Unsplash)

## 手触り

3 つの場面だけに、決まった動きと振動を当てる。音は既定でオフ。動きの長さと振動の種類は [`tokens.md`](tokens.md) の「動きと振動」。

| 場面         | 動き                                                     | 振動          |
| ------------ | -------------------------------------------------------- | ------------- |
| 残す         | 写真が帳面の行に収まり、その日の欄に墨の日付印が押される | 軽く 1 回     |
| 実績を解除   | トーストに朱の印が押される                               | 少し重く 1 回 |
| 順位が決まる | 番号が幅から 1 つに落ち着く                              | ごく軽く 1 回 |

## OS との分担

- 操作の層は OS のガラス (Liquid Glass): タブバー、＋、トースト、シート、ナビの丸いボタン。ガラスに色を足さない。色を付けるのは主な操作の ＋ だけ (金)
- 紙面の層は HINAMI: 写真、日付の欄、罫、品名、印。ガラスを使わない (Apple の指針)
- タブバーは OS のもの (expo-router の NativeTabs)、ガラスは expo-glass-effect、アイコンは SF Symbols の細め

## 使いやすさ

| 設定                 | どうする                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 文字を大きく         | 本文・品名・補足は大きくする。大きな日付と順位には上限をかける。いちばん大きい段階では、カレンダーを日ごとの一覧に替える |
| 読み上げ             | 印は飾りとして読まず、名前と条件を 1 つの言葉で読む。トーストは自動で閉じない                                            |
| コントラストを上げる | 色を 4 通りで持ち、罫と面を濃くする                                                                                      |
| 動きを減らす         | 印を押す動きと、実績の入れ替えをやめ、フェードだけにする                                                                 |
| 色だけで伝えない     | 実績の進み具合は、朱の輪と「1 / 2 回」の文字の両方で出す                                                                 |

## 決めていないこと

- ヒラギノ明朝 (W3) が、品名の大きさで細すぎないか。実機で、カタカナの多い品名を並べて見る。細い所は W6 を試す
- データ印のかすれの出し方 (react-native-svg は feTurbulence を使えないので、Skia か重ねる画像)。長い店名を印に入れるときの省き方
- 画面イメージで決まった、UX にない見た目 (日付の欄の組み方など) は、UX と一緒に詰める
- 文書をまたぐもの (残りの画面、ふだんの写真での見え方、空の画面、マップ) は [`../open-questions.md`](../open-questions.md) の「デザイン」
