## 必ず守る志向

- 写真などを使って「大人」「高級感」を演出する
- シンプルで洗練された印象。ただしオリジナリティがある
- 参考: 今はもうないアプリ「sake flight」。世界観があってかっこいい ([事例ページ](https://tacto-inc.com/work01_detail.html))

## 世界観「夜の帳面」

sake flight が「旅」(パスポート、搭乗券) で世界観をつくったのに対し、HINAMI は名前どおり「暦」でつくる。

### 原則

1. 写真が主役
2. 色を絞る
3. 日次のモチーフ

### 色

| 名前   | 値        | 用途           |
| ------ | --------- | -------------- |
| 墨     | `#16130F` | 背景           |
| 生成り | `#F2EDE4` | 文字・紙面     |
| 金     | `#B8995F` | 操作と順位だけ |
| 朱     | `#A23F2E` | 印だけ         |

### 書体 (すべて Google Fonts)

| 書体               | 用途             |
| ------------------ | ---------------- |
| しっぽり明朝       | 見出し・品名     |
| Cormorant Garamond | 日付・数字・ロゴ |
| Noto Sans JP       | 本文・操作       |

### モチーフ

日付印、帳面の罫線、朱印 (実績を御朱印帳のように埋める)。

## 起こした画面

ホーム、記録する、食事の詳細、比べる、ランキング、実績・マップ。

未着手: 地図、年間ふりかえり、つながる。

## 写真

未調達。画面の写真枠は褐色の仮の面。
おすすめは作り手自身が撮った料理と酒の写真 5〜6 枚を入れること。代案は画像生成。
