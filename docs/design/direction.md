# デザインの方向性

> **状態: 決めた (2026-11-28)**。前の案「夜の帳面」(2026-11-26) を、コンセプトの変更 (口にするものなら何でも記録できる、種類に偏らせない) に合わせて、世界観「日々の帳面」に組み直した。色の値や印の形のような細部は今の案で、画面を作りながら詰める。

- スライド: [`deck/`](deck/README.md) (オンライン版は README にリンク)
- 画面イメージ (8 枚): [`screens/index.html`](screens/index.html) をブラウザで開く。写真は Unsplash の仮置き

## 必ず守る志向

- 写真などを使って「大人」「高級感」を演出する
- シンプルで洗練された印象。ただしオリジナリティがある
- 参考: 今はもうないアプリ「sake flight」。世界観があってかっこいい ([事例ページ](https://tacto-inc.com/work01_detail.html))
- 参考: 一休.com。白い背景でも、金を使って高級感を出している (作り手の指摘。2026-11-28)

## 決めたこと (2026-11-28、作り手の判断)

| 論点   | 決めたこと                                                          | 補足                                                         |
| ------ | ------------------------------------------------------------------- | ------------------------------------------------------------ |
| 世界観 | 「日々の帳面」。帳面の比喩と「写真が主役」は前の案から残す          | 名前「日次」をそのまま言い換えた。時間帯と種類を選ばない     |
| 明暗   | 明るい紙面 (生成り) と暗い紙面 (墨) の両方を作り、OS の設定に従う   | カメラだけはいつも暗い                                       |
| 色     | 墨・生成り・金・朱の 4 つ。金は操作と順位、朱は印だけ               | 金は一休に学び、紙面ごとに濃さを変える (下の「色」)          |
| 書体   | 見出し・品名と本文は OS のヒラギノ。日付とロゴは Cormorant Garamond | しっぽり明朝と Noto Sans JP はやめる                         |
| 写真   | 画面イメージは仮置きの写真のまま進める                              | ふだんスマホで撮る写真での見え方は、PHASE 1 の実機で確かめる |

### 採らなかった案

| 案                                    | 理由                                                                                                                                                       |
| ------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 「夜の帳面」のまま                    | 夜と酒に寄って見え、朝のカフェやパン、酒を飲まない人に「自分のためのアプリ」と映りにくい                                                                   |
| 墨 1 本に絞る                         | 夜と酒に寄って見えやすく、明るい場所では見づらい                                                                                                           |
| 金をやめ、墨・生成り・朱の 3 つにする | デザイナーの提案。金は生成りの上で 2.34:1 しかないためだった。作り手が、一休のように白い背景でも金で高級感を出したいと判断し、濃さを紙面ごとに変えて残した |
| 名前の候補「一日一頁」「食の暦」      | 「日々の帳面」のほうが、名前「日次」とまっすぐつながる                                                                                                     |

## 3 つの原則

1. **写真が主役、紙面は静か**: 紙面の色は墨・生成り・金・朱の 4 つだけ。ほかの色は写真に任せる。枠や影で囲まず、余白と細い罫で区切る
2. **帳面の作法を、全画面に通す**: 名前「日次」から引いた 1 つの比喩でアプリ全体をつくる (sake flight に学ぶのは、比喩そのものではなく、1 つの比喩を全体に通すこと)
3. **朝の一杯も、夜の一皿も**: 明るい紙面と暗い紙面を同じ質で作る。どの種類の写真も、同じ枠と同じ重さで並べる。見本の写真も種類でならす

## 帳面の作法

| 作法           | 形                                                                                                  | どこで                      |
| -------------- | --------------------------------------------------------------------------------------------------- | --------------------------- |
| 日付の欄       | 左に大きな日付、右に記録。罫で 1 行ずつ (帳簿の組み方)                                              | ホーム、食事の詳細          |
| 日付印         | 残したとき、その日の欄に墨の印を押す。形は帳簿に押す日付印 (データ印: 名前・日付の帯・下の段)       | ホーム                      |
| 朱印           | 実績は朱の印。種類は丸、店は角、土地と場面は小判。まだの実績も同じ形で、朱の輪で進み具合を出す      | 実績のタブ、トースト        |
| 余白の書き込み | 記録から読み取った好みは、左に細い線を引いた注釈にする。AI を光らせず、出どころは「記録から」と書く | 好みのことば (置き場は未定) |
| 綴じる         | 1 年の帳面を綴じて見返す                                                                            | 年間ふりかえり (あとで)     |

- 印は飾り。名前・回数・日付は、印の下に文字で出す (大きな文字と読み上げのため)
- 印は写真に重ねない (写真に手を加えない)

## 明暗

- 明るい紙面 (生成り) と暗い紙面 (墨) を同じ質で作り、OS の設定に従って切り替える。色の名前は同じで、値だけを入れ替える
- 「暗い = 夜と酒、明るい = 朝とカフェ」にしない。見本も同じ中身で見せる
- カメラは、どちらでもいつも暗い (写真を見る面として、OS のカメラと同じ)

## 色

| 名前 | 明るい紙面            | 暗い紙面                  | 用途                                                           |
| ---- | --------------------- | ------------------------- | -------------------------------------------------------------- |
| 紙   | 生成り `#F3EEE6`      | 墨 `#16130F`              | 背景                                                           |
| 面   | `#EAE4D9`             | `#221E19`                 | 比べるのカード、検索欄                                         |
| 文字 | 墨 `#16130F` (16.0:1) | 生成り `#F2EDE4` (15.9:1) | 文字                                                           |
| 薄墨 | `#6B645B` (5.1:1)     | `#A39B8F` (6.7:1)         | 補足                                                           |
| 罫   | `#D6CEC0`             | `#3A342C`                 | 区切り線 (飾り)                                                |
| 金   | `#7E6A2C` (4.6:1)     | `#B8995F` (6.8:1)         | 操作と順位: ロゴ、選んだ絞り込みとタブ、＋、リンク、順位の数字 |
| 朱   | `#A23F2E` (5.5:1)     | `#D6694F` (5.3:1)         | 印だけ                                                         |

- 比は紙に対するコントラスト
- 金は本文に使わない。塗りの上の文字は、明るい紙面では生成り、暗い紙面では墨にする
- 金は一休.comに学ぶ ([デザインガイドライン](https://www.ikyu.co.jp/design_guideline/color))。一休.comレストランの主の色は `#AF9B65` (銀の混ざった、時を経た金箔のような金) で、ロゴ・アイコン・絞り込みの枠と塗りに使い、本文には使っていない。1 位とゴールド会員の色は別に `#A88304` を持つ。HINAMI の生成りの上では `#AF9B65` が 2.36:1 になるため、同じ考えのまま、明るい紙面では文字にも使える濃さにした
- 暗い紙面の金は、前の案の `#B8995F` をそのまま使う
- 高コントラストの設定用に、さらに濃い 2 通りを持つ (明・暗 × ふつう・高コントラストの 4 通り)

## 書体

| 書体                      | 用途                   | 備考                                      |
| ------------------------- | ---------------------- | ----------------------------------------- |
| ヒラギノ明朝 (OS 内蔵)    | 見出し・品名・店名     | 同梱しない                                |
| Cormorant Garamond (同梱) | 大きな日付・順位・ロゴ | 28pt 以上だけ。数字はライニング数字で組む |
| ヒラギノ角ゴ・SF Pro (OS) | 本文・操作・小さな数字 | Dynamic Type に従う                       |

- しっぽり明朝と Noto Sans JP はやめた。しっぽり明朝は 1 ウェイトで約 8.7MB と重く、カナが小さく字間が空くため、カタカナの品名が間延びする (詰めの情報も持たない)
- 大きな日付と順位は、文字の大きさの設定に上限をかける

## 写真

- 比率は 4:5 (一覧・詳細) と 1:1 (比べる・カレンダー・順位) の 2 つ
- 皿が真ん中に来るよう、自動で切り出す (Vision の注目領域)。写真そのものには手を加えない
- 写真の角はほとんど立てる (印刷した写真のように)。丸いガラスの操作と分ける

## 手触り

3 つの場面だけに、決まった動きと振動を当てる。音は既定でオフ。

| 場面         | 動き                                                     | 振動          |
| ------------ | -------------------------------------------------------- | ------------- |
| 残す         | 写真が帳面の行に収まり、その日の欄に墨の日付印が押される | 軽く 1 回     |
| 実績を解除   | トーストに朱の印が押される                               | 少し重く 1 回 |
| 順位が決まる | 番号が幅から 1 つに落ち着く                              | ごく軽く 1 回 |

## OS との分担

- 操作の層は OS のガラス (Liquid Glass): タブバー、＋、トースト、シート、ナビの丸いボタン。ガラスに色を足さない。色を付けるのは主な操作の ＋ だけ (金)
- 紙面の層は HINAMI: 写真、日付の欄、罫、品名、印。ガラスを使わない (Apple の指針)
- タブバーは OS のもの (expo-router の NativeTabs)、ガラスは expo-glass-effect、アイコンは SF Symbols の細め

## 使いやすさ

| 設定                 | どうする                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| 文字を大きく         | 本文・品名・補足は大きくする。大きな日付と順位には上限をかける。いちばん大きい段階では、カレンダーを日ごとの一覧に替える |
| 読み上げ             | 印は飾りとして読まず、名前と条件を 1 つの言葉で読む。トーストは自動で閉じない                                            |
| コントラストを上げる | 色を 4 通りで持ち、罫と面を濃くする                                                                                      |
| 動きを減らす         | 印を押す動きと、実績の入れ替えをやめ、フェードだけにする                                                                 |
| 色だけで伝えない     | 実績の進み具合は、朱の輪と「1 / 2 回」の文字の両方で出す                                                                 |

## 確かめること

- ヒラギノ明朝での見え方 (実機で、カタカナの多い品名を並べて見る)
- ふだんスマホで撮る写真 (暗い店、台所の明かり) での、明るい紙面と暗い紙面の見え方。PHASE 1 の実機で確かめる
- データ印のかすれの出し方 (react-native-svg は feTurbulence を使えないので、Skia か重ねる画像)。長い店名を印に入れるときの省き方
- 画面イメージで決まった UX にない見た目 (日付の欄の組み方など) は、UX と一緒に詰める

## レビュー

別の目のレビューを 1 回通し、指摘を反映した。

- 利用者役 5 人 (酒を飲まないカフェとパン好き、ワイン、ウイスキー、日本酒、子育て中の家ごはん): 偏りがカフェとパンに移っていた → 見本の写真をならした。帳面らしさが印に頼っていた → 一覧を帳簿の組み方にした。印が単調 → 形を 3 つに分けた
- iOS のデザインとアクセシビリティの専門家: 印の中の小さな文字に情報があった → 文字で出し直した。暗い紙面の朱が小さな文字に足りない → `#D6694F` に上げた。カメラの左下に最新の写真を出していた (写真を見に行かない決まりに反する) → アイコンにした。＋ だけが不透明 → 色を付けたガラスにした。しっぽり明朝の容量と組み → OS の明朝にした

## 前の案「夜の帳面」(2026-11-26)

スライドは [`../references/slides/design-deck/`](../references/slides/design-deck/) (`view.html` をブラウザで開く)。

sake flight が「旅」(パスポート、搭乗券) で世界観をつくったのに対し、HINAMI は名前どおり「暦」でつくる、とした案。

- 原則: 写真が主役、色を絞る、日次のモチーフ
- 色: 墨 `#16130F` (背景)、生成り `#F2EDE4` (文字・紙面)、金 `#B8995F` (操作と順位だけ)、朱 `#A23F2E` (印だけ)
- 書体: しっぽり明朝 (見出し・品名)、Cormorant Garamond (日付・数字・ロゴ)、Noto Sans JP (本文・操作)。すべて Google Fonts
- モチーフ: 日付印、帳面の罫線、朱印 (実績を御朱印帳のように埋める)
- 起こした画面: ホーム、記録する、食事の詳細、比べる、ランキング、実績 (当時は「図鑑・ラリー」)
