状態: 合意 (2026-11-27)。決まりの本文は navigation.md

タブは ホーム / 記録 / 実績 / マップ / 友だち。記録を残すボタン (＋) はタブバーとは別に右下に浮かせ、どの画面からでも押せる。ホームは自分の最近の記録を中心にし、比べると友だちは必要なときだけ出す。

  • 決まった流れ・機能
  • 案 まだ確かめていない流れ・機能

画面の中の配置や大きさは、すべて仮。

タブ

画面の移動は、基本的にタブバーで行う。タブバーには操作を置かない。お知らせと設定はタブにせず、ホームの右上に置く。

タブ 中身 ワイヤーフレーム
ホーム 自分の最近の記録。比べると友だちは必要なときだけ (下の A) このページ
記録 今までの記録のカレンダーと検索。はじめは「履歴」と呼んでいた history-flow.html
＋ (右下。タブではない) 押すとすぐカメラが開く。写真から選ぶ入り口はカメラの左下。保存したら、もとの画面にトーストで「残しました」 recording-flow.html
実績 解除した実績と、その進み具合。種類の一覧は置かない。はじめは「図鑑」と呼んでいた achievements-flow.html の A
マップ 食べた場所の地図。はじめは実績のタブの中の切り替えだった achievements-flow.html の B
友だち 友だちがシェアした食事、メッセージ、友だちの一覧 connect-flow.html
