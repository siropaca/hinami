# 種類の一覧 (UX)

> **状態: 検討中 (2026-11-27)**。3 段の持ち方と、どの段を何に使うかまで決めた。一覧の中身 (どの種類を入れるか) はまだ。

## 目的

AI が付ける「種類」の持ち方を決める。比べる (ランキングの相手)、実績のスタンプ (〇〇 N 回)、記録のタブの絞り込みが、すべてこの一覧の上に乗る。

## 3 段で持つ

```
大分類 (裏で持つ)   種類 (ふだん見せる)     細かい種類 (AI が分かれば付ける)
麺            →    ラーメン          →    醤油ラーメン、味噌ラーメン、つけ麺
              →    そば              →    ざるそば、天ぷらそば
酒            →    日本酒            →    純米大吟醸、純米酒
              →    ワイン            →    赤、白、スパークリング
肉            →    焼き鳥、焼肉 …
```

| 段         | 例                       | 使うところ                                                                                                                         |
| ---------- | ------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 大分類     | 麺、酒、肉               | 裏で持つ。スタンプのまとまり分けと、絞り込みの ▾ の見出しに使う。確認カードには出さない。食・飲は、さらにその上の裏の区分          |
| 種類       | ラーメン、日本酒、焼き鳥 | ふだん見せる段。確認カード、記録のタブの絞り込みのボタン、ランキング (比べる相手)、スタンプ (〇〇 N 回、N 種類) はこの段にそろえる |
| 細かい種類 | 醤油ラーメン、純米大吟醸 | AI が見分けられれば付けておく。記録のタブの絞り込みの ▾ から選べる。ランキングとスタンプには使わない                               |

- 「ラーメン」くらいの粒度が、比べる相手として自然 (作り手も同じ感覚)。「麺」だとラーメンとそばを比べることになり、「醤油ラーメン」だと相手が少なすぎてランキングが育たない
- 細かい種類は見分けられないことも多いので、見分けられなくても困らない段に置く
- 一覧は運営が持ち、管理画面から足せる ([`achievements.md`](achievements.md) の「運営が足す仕組み」)

## 決めていないこと

- 一覧の中身 (どの種類を入れるか、最初にいくつ用意するか)
- 一覧にないものを AI が見つけたときの扱い
- 「N 種類」のスタンプの段階 (一覧の中身が決まってから)
