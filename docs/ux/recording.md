# 記録の流れ (UX)

> **状態: 検討中**。見た目のデザインより先に、画面の流れを決める。ワイヤーフレームはこのあと起こす。

## 目的

ホームからいつもの記録までを、簡単で気軽にする。ここが重いと使われない。
PHASE 1 の関門は「作り手が 4 週間、覚えておきたい食をすべて記録できる」こと。

## 流れ

```
ホーム
 ├─ [撮る] ───────────┐
 ├─ [写真から選ぶ] ────┤ (複数枚まとめて選べる)
 │                    ▼
 │             確認カード ─ [残す] ─▶ ホーム
 └─ 履歴 (ホームから 1 ステップ奥でよい)
```

- その場で撮っても、落ち着いてから写真から選んでも、同じ流れで記録できる
- 写真から選ぶ場合は、写真に残った位置と日時を使う

## 確認カード

```
写真
[一皿] [一杯]           AI がその場で判定。違えばタップで直す
店  麺屋 ひかり ▾        推定に自信があるとき: 店名
    道玄坂・候補 3 件 ▾  自信がないとき: 地域名 (店を決め打ちしない)
メモ (任意)
               [残す]
```

| 項目        | 決まり                                                                                                    |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| 必須の入力  | なし。写真だけで記録になる                                                                                |
| 一皿 / 一杯 | 画像判定の AI がその場で付ける (1 秒未満)。1 枚に両方写っていれば両方付く。間違っていたらその場で手で直す |
| 店          | 下の「店」を参照                                                                                          |
| メモ        | 任意。品名は分からないことが多いため、必須にしない                                                        |
| 電波がない  | 保存を先に済ませ、電波が戻ったら判定する                                                                  |

## 同じ食事のまとめ方

時刻と場所で自動にまとめる。店が分からなくても必ずまとまる。

- 直前の記録から数時間以内で、その食事の最初の記録から近ければ、同じ食事にする
- 起点を「直前の記録」にしない。商店街を少しずつ移動すると、1 日分が 1 食に連なってしまうため
- 距離の幅は GPS の精度に合わせて変える。屋内の誤差で 1 食が割れないようにするため

## 店

- 店は品ごとに持つ。同じ食事と判定されたら、前の品で選んだ店を最初から入れておく
- 推定に自信があるときだけ店名を出す。ビルの中など候補が複数あるときは、地域名と候補数を出し、店を決め打ちしない
- 店の欄は毎回出す。はしごで店が変わったら、ここで別の店を選ぶと、その品から新しい食事に分かれる
- 店の欄をタップすると、近くの候補・検索・「家」・「店ではない」から選べる。候補は、近さ、行ったことがあるか、AI のジャンルと店の種類が合うか、で並べる
- 家で撮った記録は、店の候補を出さずに「家」にする
- 店のランキングと地図に載るのは、店が決まった記録だけ。間違った店がランキングに混ざらないようにするため。店が決まっていなくても、記録は残る

## 参考にした事例

| 事例                        | 型                                                                                        |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| Swarm                       | 位置の履歴や写真から、あとでチェックインする候補を出す                                    |
| Google マップのタイムライン | 自動で記録した訪問先を、あとから候補の一覧で選び直す                                      |
| Untappd                     | 店は任意。近さと自分が行った回数で候補が並ぶ                                              |
| Apple の写真アプリ          | 写真を店名ではなく地域名でまとめる                                                        |
| Foursquare                  | 店が縦に積み重なった密集地は判別が難しい、と自ら書いている (ビルの中で決め打ちしない根拠) |

## まだ確かめていない案

- 保存したあとに「比べる」を 1 問だけ出し、飛ばせるようにする。飛ばした分は後でまとめて答えられる
- ホームに記録の入り口以外のものを置くか。続けたくなる仕組みを決めるときに一緒に決める
