# 記録の流れ (UX)

> **状態: 一旦合意 (2026-11-26)**。ワイヤーフレームまで見て、この流れで進める。「案」と付けたものはまだ確かめていない。
>
> ワイヤーフレーム (画面遷移図): [`recording-flow.html`](recording-flow.html)。ブラウザで開く。

## 目的

ホームからいつもの記録までを、簡単で気軽にする。ここが重いと使われない。
PHASE 1 の関門は「作り手が 4 週間、覚えておきたい食をすべて記録できる」こと。

## 流れ

```
ホーム
 ├─ [撮る] ───────────┐
 ├─ [写真から選ぶ] ────┤ (複数枚まとめて選べる)
 │                    ▼
 │             確認カード ─ [残す] ─▶ ホーム
 └─ 履歴 (ホームから 1 ステップ奥でよい)
```

- その場で撮っても、落ち着いてから写真から選んでも、同じ流れで記録できる
- 写真から選ぶ場合は、写真に残った位置と日時を使う
- アプリで撮った写真は、端末の写真アプリにも残す。ストーリーなどほかの SNS には、そこから上げる

## 確認カード

```
写真
[一皿] [一杯]           AI がその場で判定。違えばタップで直す
店  麺屋 ひかり ▾        推定に自信があるとき: 店名
    道玄坂・候補 3 件 ▾  自信がないとき: 地域名 (店を決め打ちしない)
メモ (任意)
               [残す]
```

| 項目        | 決まり                                                                                                    |
| ----------- | --------------------------------------------------------------------------------------------------------- |
| 必須の入力  | なし。写真だけで記録になる                                                                                |
| 一皿 / 一杯 | 画像判定の AI がその場で付ける (1 秒未満)。1 枚に両方写っていれば両方付く。間違っていたらその場で手で直す |
| 店          | 下の「店」を参照                                                                                          |
| メモ        | 任意。品名は分からないことが多いため、必須にしない                                                        |
| 電波がない  | 保存を先に済ませ、電波が戻ったら判定する                                                                  |

## 同じ食事のまとめ方

時刻と場所で自動にまとめる。店が分からなくても必ずまとまる。

- 直前の記録から数時間以内で、その食事の最初の記録から近ければ、同じ食事にする
- 起点を「直前の記録」にしない。商店街を少しずつ移動すると、1 日分が 1 食に連なってしまうため
- 距離の幅は GPS の精度に合わせて変える。屋内の誤差で 1 食が割れないようにするため

## 店

- 店は品ごとに持つ。同じ食事と判定されたら、前の品で選んだ店を最初から入れておく
- 推定に自信があるときだけ店名を出す。ビルの中など候補が複数あるときは、地域名と候補数を出し、店を決め打ちしない
- 店の欄は毎回出す。はしごで店が変わったら、ここで別の店を選ぶと、その品から新しい食事に分かれる
- 店の欄をタップすると、近くの候補・検索・「家」・「店ではない」から選べる。候補は、近さ、行ったことがあるか、AI のジャンルと店の種類が合うか、で並べる
- 家で撮った記録は、店の候補を出さずに「家」にする
- 店のランキングと地図に載るのは、店が決まった記録だけ。間違った店がランキングに混ざらないようにするため。店が決まっていなくても、記録は残る

## 参考にした事例

| 事例                        | 型                                                                                        |
| --------------------------- | ----------------------------------------------------------------------------------------- |
| Swarm                       | 位置の履歴や写真から、あとでチェックインする候補を出す                                    |
| Google マップのタイムライン | 自動で記録した訪問先を、あとから候補の一覧で選び直す                                      |
| Untappd                     | 店は任意。近さと自分が行った回数で候補が並ぶ                                              |
| Apple の写真アプリ          | 写真を店名ではなく地域名でまとめる                                                        |
| Foursquare                  | 店が縦に積み重なった密集地は判別が難しい、と自ら書いている (ビルの中で決め打ちしない根拠) |

## まだ確かめていない案

ワイヤーフレームでは「案」と付けて破線で描いている。

| 対象            | 案                                                                                                                                                               |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 比べる          | 保存したあとに 1 問だけ出し、飛ばせる。飛ばした分は後でまとめて答えられる。相手は同じジャンルの記録から出す                                                      |
| 取り消し        | 保存したあと、数秒だけ「取り消す」を出す                                                                                                                         |
| 確認カードの ×  | 記録をやめてホームへ戻る。メモを書いていたときだけ確かめる。撮り直しは写真の上から行う                                                                           |
| 食事の分け直し  | 確認カードの食事の表示 (「同じ食事 · 2 品目」) をタップし、「新しい食事にする / 前の食事に入れる」を選ぶ。家で朝と昼を食べたときなど、店で分けられない場合に使う |
| 店を後から選ぶ  | 同じ食事で店が決まっていない前の品にも、同じ店を入れる                                                                                                           |
| 家              | 初めて「家」を選んだ場所を覚え、次からはそこを家にする                                                                                                           |
| 位置がない写真  | 受け取った写真、スクリーンショット、位置情報オフのとき。店は検索だけにし、食事のまとまりは時刻だけで決める                                                       |
| 電波がない (店) | 地域名は端末の位置から出し、店の推定は電波が戻ってから行う                                                                                                       |
| 判定できない    | 一皿・一杯のどちらも付けずに出し、手で選ぶ。選ばなくても残せる                                                                                                   |
| 写真から複数枚  | 食事ごとにまとめた一覧で確認し、まとめて残す。品ごとに外せる。1 枚だけ選んだときは確認カードへ進む                                                               |
| 記録済みの写真  | 写真から選ぶとき、HINAMI で記録済みの写真は外して見せる。撮った写真を端末にも残すので、同じ品を二重に記録しないようにする                                        |

## 決めていないこと

- 店が決まっていない記録を、あとでどこで直すか (履歴の中身と一緒に決める)
- ホームに記録の入り口以外のものを置くか (続けたくなる仕組みと一緒に決める)。あとから気の知れた人の記録を置ける場所は残す
- 写真から複数枚を残したときに、比べるをどう出すか
- いいお酒を買ったときのように、まだ口にしていないもの (買ったボトルなど) をどう記録するか。一皿・一杯にも、店で食べた食事にも当てはまらない
