# お知らせと設定 (UX)

> **状態: 決めた (2026-11-27)**。作り手から任されて決めた。出す要素だけを決め、見た目はデザインのフェーズで決める。気になる点があれば直す。
>
> ワイヤーフレーム: [`settings-flow.html`](settings-flow.html)。ブラウザで開く。

## 目的

ホームの右上に置くお知らせと設定に、何を出すかを決める ([`navigation.md`](navigation.md))。設定に置くものは、ほかの論点で決めてきたものを 1 か所に集める。

## お知らせ

ほかに置き場のない知らせだけを、新しい順に並べる。

| 要素                     | 決まり                                                                                                                                                                              |
| ------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 運営からのお知らせ       | 日付と中身。プッシュ通知で届いたときは、タップでここに来る。中身は未決 ([`connect.md`](connect.md))                                                                                 |
| さかのぼって解除した実績 | 運営が実績や種類を足して、過去の記録で解除された実績。足した 1 回ごとにまとめて 1 件にする。タップで実績のタブに移る ([`achievements.md`](achievements.md)、[`kinds.md`](kinds.md)) |
| 未読の印                 | 読んでいないものがあるとき、ホームの右上の「お知らせ」に付ける                                                                                                                      |

- 友だちの動き (友だちになった、反応、友だちの新しい食事) は入れない。友だちのタブに置き場があるので、同じものを 2 か所に並べない
- 電波がなく判定を待っていた記録の解除は、ここには入れない。今の決まりのまま、次にホームを開いたときに出す ([`achievements.md`](achievements.md))

## 設定

| 要素                           | 中身                                                                                                                                                                                | 決めたところ                                                 |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 通知                           | 種類ごとに止める (友だちになった、スタンプ・メッセージ、友だちの新しい食事、運営からのお知らせ)。チュートリアルで「あとで」を選んだ人には「受け取る」を出し、押すと OS の許可を出す | [`connect.md`](connect.md)、[`onboarding.md`](onboarding.md) |
| 名前                           | 友だちに見える名前を変える                                                                                                                                                          | [`connect.md`](connect.md)                                   |
| 覚えた家                       | 一覧で見て、消せる。消すと、その近くでは家にしなくなる。過去の記録の「家」はそのまま                                                                                                | [`recording.md`](recording.md)                               |
| 写真を端末に残す               | オン・オフ                                                                                                                                                                          | [`onboarding.md`](onboarding.md)                             |
| ブロックした人                 | 一覧と、解除。解除しても友だちには戻らず、もう一度 QR コードで友だちになる                                                                                                          | [`connect.md`](connect.md)                                   |
| アカウント                     | Google でサインイン中、ログアウト、アカウントを削除                                                                                                                                 | [`onboarding.md`](onboarding.md)                             |
| 利用規約・プライバシーポリシー | それぞれへのリンク                                                                                                                                                                  | [`onboarding.md`](onboarding.md)                             |
| 問い合わせ                     | 運営への連絡先 (App Store の審査ガイドライン 1.2)                                                                                                                                   | [`connect.md`](connect.md)                                   |
| バージョン                     | アプリのバージョン。問い合わせのときに使う                                                                                                                                          | ここで足した                                                 |

- 名前とブロックした人は、友だちの機能を使い始めてから出す。それまでは中身がないため
- 覚えた家は、間違えて覚えたとき (友だちの家など) に消すために置く。家の場所は人に見せたくない情報なので、自分で消せるようにもする
- カメラと位置情報の許可は、設定に置かない。OS の設定にあるため。断ったあとに使おうとしたときは、その場で OS の設定へ案内する。写真を端末に残すのは HINAMI の動きなので、設定に置く

## 入れないもの

| もの                         | 理由                                                                                                                                                             |
| ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| お知らせに友だちの動きを出す | 友だちのタブに置き場がある。同じものを 2 か所に並べない                                                                                                          |
| 記録の書き出し               | 移す先がなく、大事な写真は端末に残るため (作り手の判断)。サービスを終えるときの記録の扱いは、規約と一緒に決める ([`../open-questions.md`](../open-questions.md)) |

## 決めていないこと

- 運営からのお知らせの中身 (宣伝を含むか。含むなら通知のお願いの画面に別の同意を置く。[`onboarding.md`](onboarding.md))
- 問い合わせの受け方 (フォームか、メールか)
