実績の見返りは最初の数週に厚く、2〜3 か月目から減る。そこで「記憶している」と「育つ」を、時期で分けた 3 つで返す。数週からの「前にも」、3 か月目からの「季節と年のアルバム」、1 年目からの「毎年の楽しみ」。どれも通知で押さず、自分だけに見せる。出す要素だけを決め、見た目はデザインのフェーズで決める。

C. 毎年の楽しみ (1 年目から)

毎年同じ季節に口にしている、大好きな品を、その季節に入ったらホームのカードで出す。1 つの季節に 1〜2 回まで。「○年前の今日」は出さない。

D. 思い出に出さない

嫌な思い出を不意に見せないため、食事・期間・店の単位で「思い出に出さない」にできる。前にも、アルバム、毎年の楽しみのどれにも出なくなる。記録のタブと検索には残る。
