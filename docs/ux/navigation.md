# 画面の構成 (タブとホーム)

> **状態: 合意 (2026-11-27)**。タブの構成、記録の入り口、保存したあとの知らせ方、ホームの中身まで決めた。
>
> ワイヤーフレーム: [`navigation-flow.html`](navigation-flow.html)。ブラウザで開く。

## タブ

```
┌───────────────────────────┐
│ HINAMI          [お知らせ] [設定]  │  ← ホームの右上
│                                    │
│   (ホームの中身は下の「ホーム」)   │
│                                    │
│ ホーム  履歴  ( 記録 )  図鑑  友だち │
└───────────────────────────┘
```

| タブ          | 中身                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------- |
| ホーム        | 自分の最近の記録を中心にし、比べると友だちは必要なときだけ出す (下の「ホーム」)                    |
| 履歴          | カレンダーと検索 ([`history.md`](history.md))                                                      |
| 記録 (真ん中) | ほかのタブより大きく、目立たせる。押すとすぐカメラが開く。写真から選ぶ入り口は、カメラの画面の左下 |
| 図鑑          | 図鑑 (集めた種類と地域)、ランキング、解除した実績の一覧をまとめる。中の分け方は図鑑の画面で決める  |
| 友だち        | つながる ([`connect.md`](connect.md))                                                              |

- 記録の入り口をタブバーの真ん中に置き、どの画面からでも記録を始められるようにする (作り手の判断)
- 図鑑・ランキング・実績は「育つ」の部分で、続けたくなる仕組みの中心。「マイページ」などの奥に入れると見えなくなるので、タブにする
- お知らせ (運営から) と設定は、タブにせず、ホームの右上に置く。設定はあまり開かないため

### 採らなかった案

| 案                                                               | 採らない理由                                     |
| ---------------------------------------------------------------- | ------------------------------------------------ |
| ホームをカメラにする (開いたらすぐ撮れる)                        | 作り手が、記録はタブバーの真ん中に置く形を選んだ |
| 右端を「マイページ」にし、図鑑・ランキング・実績・設定をまとめる | 育つ部分が奥に隠れる                             |

## ホーム

自分の最近の記録を中心にする。比べると友だちは、必要なときだけ出す。

```
ホーム
┌───────────────────────────┐
│ HINAMI          [お知らせ] [設定]  │
│ ┌ どちらが好き?     ラーメン ┐   │  ← 比べる (あるときだけ)
│ └──────────────────┘   │
│ 最近の記録              すべて ›   │  ← 履歴へ
│ 11/26 鮨 はやし   ▢ ▢ ▢           │
│ 11/25 家          ▢                │
│ 11/24 麺屋 ひかり ▢ ▢             │
│ 友だち  ○○○ 新しい食事 3 ›       │  ← 新しいものがあるときだけ
│ ホーム  履歴  ( 記録 )  図鑑  友だち │
└───────────────────────────┘
```

| 項目              | 決まり                                                                                                                             |
| ----------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| 比べるの 1 問     | 食べたあとに開いたときだけ、いちばん上に出す ([`compare.md`](compare.md))                                                          |
| 最近の記録        | 自分の記録を食事単位で数件並べる。食事をタップすると食事の詳細、「すべて」で履歴へ移る                                             |
| 友だち            | 友だちの新しい食事があるときだけ、下に 1 行で出す。タップで友だちのタブへ。メインにならない程度の動線 ([`connect.md`](connect.md)) |
| 記録が 0 件のとき | 真ん中の記録ボタンへ案内する                                                                                                       |
| 出さないもの      | 図鑑の数字や「あと N 回」。実績の一覧は図鑑のタブで見る ([`achievements.md`](achievements.md))                                     |

- 残した直後に、直前の食事が積み重なっていくのが見える。店が決まっていない食事を直すのも、ここからすぐできる
- 一人で使うときは、最近の記録だけのすっきりした画面になる
- ホームに図鑑や実績の進み具合を並べる案は採らなかった。図鑑のタブと中身が重なり、「あと N 回」をホームに出さない実績の決まりにも反するため

## 記録の入り口と、保存したあと

| 項目         | 決まり                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 撮る         | 記録 → シャッター → 残す の 3 タップ                                                                                                 |
| 写真から選ぶ | 記録 → カメラの左下の「写真から選ぶ」                                                                                                |
| 保存したあと | 記録を始めた画面に戻り、トーストで「残しました」を出す。解除した実績、図鑑への追加、取り消すも同じトーストに出す。ホームには移らない |

## 参考にした事例

| 事例                    | 型                                                             |
| ----------------------- | -------------------------------------------------------------- |
| 銀行アプリ (SMBC)       | タブバーの真ん中に、いちばん使う操作 (振込・振替) を大きく置く |
| インスタ、LINE のカメラ | カメラの画面の左下から、端末の写真を選べる                     |

## 決めていないこと

- 図鑑のタブの中の分け方 (図鑑、ランキング、実績)
