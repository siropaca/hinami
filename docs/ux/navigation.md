# 画面の構成 (タブとホーム)

> **状態: 検討中 (2026-11-27)**。タブの構成、記録の入り口、保存したあとの知らせ方まで決めた。ホームの中身はまだ決めていない。

## タブ

```
┌───────────────────────────┐
│ HINAMI          [お知らせ] [設定]  │  ← ホームの右上
│                                    │
│   (ホームの中身は未定)             │
│                                    │
│ ホーム  履歴  ( 記録 )  図鑑  友だち │
└───────────────────────────┘
```

| タブ          | 中身                                                                                               |
| ------------- | -------------------------------------------------------------------------------------------------- |
| ホーム        | まだ決めていない。友だちのタブへの軽い動線は置いてよい ([`connect.md`](connect.md))                |
| 履歴          | カレンダーと検索 ([`history.md`](history.md))                                                      |
| 記録 (真ん中) | ほかのタブより大きく、目立たせる。押すとすぐカメラが開く。写真から選ぶ入り口は、カメラの画面の左下 |
| 図鑑          | 図鑑 (集めた種類と地域)、ランキング、解除した実績の一覧をまとめる。中の分け方は図鑑の画面で決める  |
| 友だち        | つながる ([`connect.md`](connect.md))                                                              |

- 記録の入り口をタブバーの真ん中に置き、どの画面からでも記録を始められるようにする (作り手の判断)
- 図鑑・ランキング・実績は「育つ」の部分で、続けたくなる仕組みの中心。「マイページ」などの奥に入れると見えなくなるので、タブにする
- お知らせ (運営から) と設定は、タブにせず、ホームの右上に置く。設定はあまり開かないため

### 採らなかった案

| 案                                                               | 採らない理由                                     |
| ---------------------------------------------------------------- | ------------------------------------------------ |
| ホームをカメラにする (開いたらすぐ撮れる)                        | 作り手が、記録はタブバーの真ん中に置く形を選んだ |
| 右端を「マイページ」にし、図鑑・ランキング・実績・設定をまとめる | 育つ部分が奥に隠れる                             |

## 記録の入り口と、保存したあと

| 項目         | 決まり                                                                                                                               |
| ------------ | ------------------------------------------------------------------------------------------------------------------------------------ |
| 撮る         | 記録 → シャッター → 残す の 3 タップ                                                                                                 |
| 写真から選ぶ | 記録 → カメラの左下の「写真から選ぶ」                                                                                                |
| 保存したあと | 記録を始めた画面に戻り、トーストで「残しました」を出す。解除した実績、図鑑への追加、取り消すも同じトーストに出す。ホームには移らない |

## 参考にした事例

| 事例                    | 型                                                             |
| ----------------------- | -------------------------------------------------------------- |
| 銀行アプリ (SMBC)       | タブバーの真ん中に、いちばん使う操作 (振込・振替) を大きく置く |
| インスタ、LINE のカメラ | カメラの画面の左下から、端末の写真を選べる                     |

- 図鑑のタブの中の分け方 (図鑑、ランキング、実績)
