# 画面の構成 (タブとホーム)

> **状態: 合意 (2026-11-27)**。タブの構成、記録の入り口、保存したあとの知らせ方、ホームの中身まで決めた。同じ日に、記録を残すボタンをタブバーの真ん中から右下に移し、「履歴」のタブを「記録」と呼ぶことにした。さらに、実績のタブの中の切り替えだったマップを、記録のタブの中の切り替えに移し、タブを 4 つにした (間に一度、別のタブにした)。 2026-11-28 に、＋ → シャッターの 2 タップで残る形にし、写真なしで残す入り口、ホームの気持ちの 1 問、季節と年のアルバムと毎年の楽しみのカードを足した。
>
> ワイヤーフレーム: [`navigation-flow.html`](navigation-flow.html)。ブラウザで開く。

## タブ

```
┌───────────────────────────┐
│ HINAMI          [お知らせ] [設定]  │  ← ホームの右上
│                                    │
│   (ホームの中身は下の「ホーム」)   │
│                                    │
│                            ( ＋ )  │  ← 記録を残す (どの画面でも同じ位置)
│ ホーム    記録    実績    友だち   │
└───────────────────────────┘
```

| タブ   | 中身                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------- |
| ホーム | 自分の最近の記録を中心にし、気持ちの 1 問と友だちは必要なときだけ出す (下の「ホーム」)            |
| 記録   | 今までの記録のカレンダーと検索、マップ ([`history.md`](history.md))。はじめは「履歴」と呼んでいた |
| 実績   | 解除した実績と、その進み具合 ([`achievements.md`](achievements.md))                               |
| 友だち | つながる ([`connect.md`](connect.md))                                                             |

- 記録を残すボタン (＋) は、タブバーとは別に右下に浮かせる。どの画面からでも押せる (作り手の判断)
- タブバーは画面を移るためだけに使い、操作を置かない (Apple のガイドライン)。＋ は押してもタブが切り替わらずカメラが開く操作なので、タブバーに入れない
- 実績は「育つ」の部分で、続けたくなる仕組みの中心。「マイページ」などの奥に入れると見えなくなるので、タブにする
- マップは、記録のタブの中で、カレンダーと切り替えて見る (2026-11-27、作り手の判断)。マップに出すのは記録のタブと同じ自分の食事で、違うのは見せ方だけのため。同じ中身の見せ方の違いは 1 か所で切り替え、中身が違うものをタブで分ける。検索と種類の絞り込みも、そのままマップに効く ([`history.md`](history.md))
- マップは、はじめ実績のタブの中の切り替えで、そのあと一度、別のタブにした。実績とマップは見るものが違う (進み具合と場所) ので実績から分け、記録とは中身が同じなので記録に入れた
- タブは 4 つ。iPhone のタブバーに置けるのは 5 つまで (Apple のガイドライン)
- 実績のタブには種類の一覧を置かない。種類で探すのは記録のタブだけにする (作り手の判断。同じ一覧を 2 か所に作らない)。ランキングは、記録のタブを種類で絞ったときに入口を出す ([`compare.md`](compare.md))
- タブの名前は「実績」(はじめは「図鑑」)。中身も「実績」と呼び、「スタンプ」とは呼ばない (作り手の判断)。友だちに送る反応のスタンプとも呼び分けられる
- お知らせ (運営から) と設定は、タブにせず、ホームの右上に置く。設定はあまり開かないため。お知らせと設定に出す要素は [`settings.md`](settings.md)

### 採らなかった案

| 案                                                               | 採らない理由                                                                                                                                             |
| ---------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ホームをカメラにする (開いたらすぐ撮れる)                        | 作り手が、記録の入り口をホームの外に置く形を選んだ                                                                                                       |
| 記録ボタンをタブバーの真ん中に大きく置く (銀行アプリの SMBC 型)  | タブバーは画面の移動に使い、操作を置かない (Apple のガイドライン)。押しても画面が切り替わらないボタンが 1 つだけ混ざり、ほかのタブと振る舞いがそろわない |
| 右端を「マイページ」にし、図鑑・ランキング・実績・設定をまとめる | 育つ部分が奥に隠れる                                                                                                                                     |
| 実績のタブの中で、実績とマップを切り替える                       | 実績とマップは見るものが違う。マップが切り替えの奥に隠れる                                                                                               |
| マップを別のタブにする                                           | 記録のタブと中身が同じで、見せ方が違うだけ。絞り込みを 2 か所に作るか、マップでは絞れないかのどちらかになる                                              |

## ホーム

自分の最近の記録を中心にする。気持ちの 1 問と友だちは、必要なときだけ出す。

```
ホーム
┌───────────────────────────┐
│ HINAMI          [お知らせ] [設定]  │
│ ┌ 特製醤油は、いかがでしたか? ┐ │  ← 気持ちの 1 問 (あるときだけ)
│ └──────────────────┘   │
│ 最近の記録              すべて ›   │  ← 記録のタブへ
│ 11/26 鮨 はやし   ▢ ▢ ▢           │
│ 11/25 家          ▢                │
│ 11/24 麺屋 ひかり ▢ ▢             │
│ 友だち  ○○○ 新しい食事 3 ›       │  ← 新しいものがあるときだけ
│                            ( ＋ )  │
│ ホーム    記録    実績    友だち   │
└───────────────────────────┘
```

| 項目                 | 決まり                                                                                                                                                                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 気持ちの 1 問        | 食べたあとに開いたときだけ、いちばん上に出す ([`compare.md`](compare.md))                                                                                                                                                                   |
| 最近の記録           | 自分の記録を食事単位で数件並べる。食事をタップすると食事の詳細、「すべて」で記録のタブへ移る。保存のあとに付いた種類と店も、ここにそのまま出る。店が決まらなかった食事だけ、その行に「店を選ぶ」を出す (件数は出さず、ためない。2026-11-28) |
| 季節と年のアルバム   | 季節や年が終わったあと、次に開いたときにカードで知らせる。記録が足りる期間だけ ([`memory.md`](memory.md))                                                                                                                                   |
| 毎年の楽しみ         | 1 年以上使った人に、その季節に入ったらカードで出す。1 つの季節に 1〜2 回まで ([`memory.md`](memory.md))                                                                                                                                     |
| カードが重なったとき | いちばん上のカードは一度に 1 枚。気持ちの 1 問 → 季節と年のアルバム → 毎年の楽しみ の順に出し、出せなかったものは次に開いたときに出す。気持ちは 7 日で聞けなくなるので先にする                                                              |
| 友だち               | 友だちの新しい食事があるときだけ、下に 1 行で出す。タップで友だちのタブへ。メインにならない程度の動線 ([`connect.md`](connect.md))                                                                                                          |
| 記録が 0 件のとき    | 右下の ＋ へ案内する                                                                                                                                                                                                                        |
| 出さないもの         | 実績の数字や「あと N 回」。実績の一覧は実績のタブで見る ([`achievements.md`](achievements.md))                                                                                                                                              |

- 残した直後に、直前の食事が積み重なっていくのが見える。店が決まっていない食事を直すのも、ここからすぐできる
- 一人で使うときは、最近の記録だけのすっきりした画面になる
- ホームに実績の進み具合を並べる案は採らなかった。実績のタブと中身が重なり、「あと N 回」をホームに出さない実績の決まりにも反するため

## 記録の入り口と、保存したあと

| 項目           | 決まり                                                                                                                                                                                                                                                                                                |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 撮る           | ＋ → シャッターの 2 タップで残る (2026-11-28。撮ったら残る。[`recording.md`](recording.md))                                                                                                                                                                                                           |
| 写真から選ぶ   | ＋ → カメラの左下の「写真から選ぶ」                                                                                                                                                                                                                                                                   |
| 写真なし       | ＋ → カメラの右下の「写真なし」。＋ の長押しでも、カメラを開かずに残せる ([`recording.md`](recording.md) の「写真なしで残す」)                                                                                                                                                                        |
| ロック画面から | ロック画面、コントロールセンター、アクションボタンから、HINAMI のカメラを開けるようにする (作り手の判断)。標準のカメラで撮って、HINAMI に入れ忘れるのを減らすため。撮ったあと、ロックを解除してからの流れと、Expo で作れるかは、技術の確認で確かめる ([`../open-questions.md`](../open-questions.md)) |
| 保存したあと   | 撮ったときも写真から選んだときも、記録を始めた画面に戻り、トーストで「残しました」を出す (ロック画面などから開いたときはホーム)。トーストの「直す」から確認カードを開ける。解除した実績、はじめての種類、取り消すも同じトーストに出す。アプリの中から始めたときは、ホームに移らない                   |
| 余白           | ＋ が一覧のいちばん下やトーストに重ならないよう、画面の下に余白を取る。トーストは ＋ の上に出す                                                                                                                                                                                                       |

## 参考にした事例

| 事例                    | 型                                                                              |
| ----------------------- | ------------------------------------------------------------------------------- |
| Slack                   | タブバーとは別に、右下に新規作成のボタンを浮かせる                              |
| 銀行アプリ (SMBC)       | タブバーの真ん中に、いちばん使う操作 (振込・振替) を大きく置く (採らなかった型) |
| インスタ、LINE のカメラ | カメラの画面の左下から、端末の写真を選べる                                      |
