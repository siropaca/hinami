# 比べる (自分のランキング)

> **状態: 合意 (2026-11-26)**。聞くタイミングと、順位の決め方まで決めた。

ワイヤーフレーム: [`recording-flow.html`](recording-flow.html) の「F. 比べる (食べたあと)」。

## 目的

点数はつけずに、「どちらが好き?」の 2 択に答えるだけで、種類ごとの自分の好きな順が育つ ([`../concept.md`](../concept.md))。記録の手軽さは崩さない。

## いつ聞くか

保存した直後には聞かない。食べたあと、次にアプリを開いたときに、ホームのカードで 1 問だけ聞く。

- 料理はたいてい食べる前に撮るので、保存した直後はまだ味を知らない
- 保存の流れに画面を足さないので、記録は最短 3 タップのまま
- 写真から選んで残した記録はもう食べ終えているので、保存後のトーストが消えたらすぐに出してよい

```
ホーム (食べたあと、次に開いたとき)
┌─────────────────────────────┐
│ どちらが好き?               ラーメン │
│ [今回: 麺屋 ひかり] [前の: 中華そば 青葉] │
└─────────────────────────────┘
        ↓ 答える
┌─────────────────────────────┐
│ 3〜4 位まで絞れました     続けて比べる │
└─────────────────────────────┘
```

| 項目             | 決まり                                                                                                                                                           |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 出す場所         | ホームのカード。別の画面にしない。アプリを開いたときに出す問いなので、プッシュ通知は使わない                                                                     |
| 数               | アプリを開いたときに 1 問だけ                                                                                                                                    |
| 何を聞くか       | 順位の幅がいちばん広い品。同じ種類に比べる相手がいる品だけが対象                                                                                                 |
| 保存後のトースト | 「残しました」のトースト (実績・図鑑への追加を含む) とは同時に出さない。それが消えてから、ホームのカードで出す                                                   |
| 答え方           | 2 つのどちらかをタップする。触らなければ流れる                                                                                                                   |
| 続けて比べる     | 答えたあと、カードに小さく出す。押さなくてよい。押せばその場で順位を決めきれる                                                                                   |
| ためない         | 「未回答 N 件」のようにためない。次に開いたときは、そのとき順位の幅がいちばん広い品から聞き直す                                                                  |
| 相手             | 自分の記録だけ。最初の数週は同じ種類の相手が少なく、問いはあまり出ない。比べるのは、3 段の真ん中の「種類」(ラーメン、日本酒など) どうし ([`kinds.md`](kinds.md)) |
| いつでも比べる   | ランキングの画面からは、いつでも比べられる                                                                                                                       |
| 入口             | 記録のタブを種類で絞ったときだけ、一覧の上にその種類のランキングの入口を出す。比べる相手がいないうちは出さない                                                   |

必ず答えさせる Beli と比べて、答えが集まる数は少なく、ランキングが育つのも遅くなる。記録を気軽にすることを優先する前提に合うので、それを受け入れる。

## 順位の決め方

比べた答えを使って、新しい品を今のランキングの中に二分で挿し込む (Beli と同じ型)。1 問答えるたびに、入りうる順位の幅が半分になる。

```
いまのラーメン 7 杯 (好きな順)
1 A   2 B   3 C   4 D   5 E   6 F   7 G

新しい H を入れる
1 問目: H と D (真ん中)  → H が好き → H は 1〜4 位のどこか
2 問目: H と B           → B が好き → H は 3〜4 位
3 問目: H と C           → H が好き → H は 3 位に決まる
```

- 順位が決まるまでの問いの数は、同じ種類の品の数で決まる。8 品なら 3 問、16 品なら 4 問、32 品なら 5 問
- 順位は答えた範囲で決まる。品どうしの差を点数で持たない
- ランキングの画面では、順位が決まった品は番号で、まだ決まっていない品は「3〜4 位」のように幅で見せる
- ランキングの画面では手で並べ替えられる。好みが変わったときや、答えを間違えたときのため

### 採らない方式

| 方式                                               | 採らない理由                                                                                               |
| -------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| 保存した直後に 1 問 (前の案)                       | 食べる前に聞くことになる。保存のたびに画面が 1 枚増え、最短 3 タップが 4 タップになる                      |
| 1 回の食事で 1 問、答えなければ差し替える (前の案) | 新しい品が「1〜4 位のどこか」のまま止まりやすく、ランキングが暫定ばかりになる                              |
| 勝ち負けから見えない点数を推定する (Elo など)      | 答えるたびにほかの品の順位まで揺れる。なぜその順位なのかを説明しにくく、自分の好きな順を作る用途に合わない |
| ランキングの画面でしか聞かない                     | 答えが集まらない                                                                                           |

## 参考にした事例

| 事例 | 型                                                                                                                              |
| ---- | ------------------------------------------------------------------------------------------------------------------------------- |
| Beli | 店に行ったあとに記録し、「好き / 普通 / 好きでない」を選んでから 2 択を数問続けて順位を決める。2 択が続くのは面倒という声もある |

## 決めていないこと

- 種類の一覧の中身 (どの種類を入れるか)。粒度は「ラーメン」「日本酒」くらいに決めた ([`kinds.md`](kinds.md))
