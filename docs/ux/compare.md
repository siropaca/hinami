# 気持ちと比べる (自分のランキング)

> **状態: 合意 (2026-11-26)**。2026-11-28 に、ホームで聞くのを「どちらが好き?」の 2 択から「そのときの気持ち」(大好き / 好き / ふつう / 合わなかった) に改めた。「大好き」と、食事全体の気持ちも足した。2 択は、好きなものどうしの順番を決めたい人が、ランキングの画面で自分から使う (作り手の判断)。同じ日に、答えにくい組み合わせのための「比べられない」と、聞く品を食べてから日が浅い品に絞る決まりを置いた。

ワイヤーフレーム: [`recording-flow.html`](recording-flow.html) の「F. 気持ちと比べる (食べたあと)」。

## 目的

点数はつけない。残すのは、そのときの気持ちと、どちらが好きかだけ ([`../concept.md`](../concept.md))。気持ちで、好き・苦手・好みの強さを知る。好きなものどうしの順番 (自分の 1 位のラーメン、いちばん好きな日本酒) は、決めたい人だけが 2 択で決める。記録の手軽さは崩さない。

## なぜ改めたか

- 2 択だけでは順番しか分からない。「どれもいまいちの中の 1 位」と「本当に好きな 1 位」を見分けられず、苦手も、相手のいない品 (はじめての種類) の気持ちも残らない。そのときの気持ちは、あとから聞き直せない ([`../data.md`](../data.md))
- ホームの 2 択は、答えが集まらない。Beli は店に行くたびに何問も答えさせ、1 回の訪問が 1 件になる。HINAMI は答えなくても流れ、ホームで聞くのは 1 問だけで、品は 1 日に何品もある。順位が育つほど答えが集まらない
- 気持ちは、相手がいなくても聞ける。いろいろな種類を少しずつ食べる人の好みも分かる
- 好きの段と苦手の段を粗く取り、順番は 2 択で取る組み合わせは、事例と研究が支える (下の「参考にした事例」)
- 「大好き」を分ける (2026-11-28、作り手の判断)。好きなものと、本当に大好きなものを分けたい人が多いため。Netflix も 2022 年に同じ理由で「大好き」を足した

## そのときの気持ち (ホームのカード)

保存した直後には聞かない。食べたあと、次にアプリを開いたときに、ホームのカードで 1 問だけ聞く。

- 料理はたいてい食べる前に撮るので、保存した直後はまだ味を知らない
- 保存の流れに画面を足さないので、記録は最短 2 タップ (＋ → シャッター) のまま
- 写真から選んで残した記録はもう食べ終えているので、保存後のトーストが消えたらすぐに出してよい

```
ホーム (食べたあと、次に開いたとき)
┌─────────────────────────────┐
│ 特製醤油 · 麺屋 ひかり は、いかがでしたか? │
│ [大好き] [好き] [ふつう] [合わなかった]    │
└─────────────────────────────┘
```

| 項目             | 決まり                                                                                                                                                                                                                                                                                     |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 出す場所         | ホームのカード。別の画面にしない。アプリを開いたときに出す問いなので、プッシュ通知は使わない                                                                                                                                                                                               |
| 数               | アプリを開いたときに 1 問だけ                                                                                                                                                                                                                                                              |
| 聞くもの         | 「〇〇は、いかがでしたか?」に、大好き / 好き / ふつう / 合わなかった で答える (言葉は今の案)。「合わなかった」は、料理の出来を責めず、自分に合わなかったと言う言葉にする。家族や自分が作った料理にも付くため                                                                               |
| 何を聞くか       | 食べてから日が浅い品 (今の案: 7 日以内) のうち、気持ちがまだない品を、新しい順に聞く。相手のいない品、「その他」の品、店が決まらない品にも聞く。1 つの食事の同じ種類の品は、ホームでは 1 品だけ聞く (コースで同じ種類が並んでも、問いが続かないように)。ほかの品は、品の画面から付けられる |
| 同じ名前の品     | 前に気持ちを付けた品と同じ名前なら、聞き直さない (毎日のコーヒーなど)                                                                                                                                                                                                                      |
| 保存後のトースト | 「残しました」のトースト (実績と、はじめての種類を含む) とは同時に出さない。それが消えてから、ホームのカードで出す                                                                                                                                                                         |
| 品の示し方       | 写真と、「名前 → 店 → 日付」の順。名前がないときは店と日付。家で食べた買ってきた品は、買った店で示す ([`recording.md`](recording.md) の「買ってきたもの」)。写真のない品は、写真の代わりに種類を出す。同じ店の 2 杯や、家の品どうしも見分けられるようにする                                |
| 答え方           | 4 つのどれかをタップする。触らなければ流れる                                                                                                                                                                                                                                               |
| ためない         | 「未回答 N 件」のようにためない。次に開いたときは、そのとき聞ける品のうち、いちばん新しい品から聞き直す                                                                                                                                                                                    |
| 付け直す         | 品の画面からいつでも付け直せる。付け直しても、前の答えは残す ([`../data.md`](../data.md))                                                                                                                                                                                                  |
| 見せる範囲       | 自分だけ。数字にせず、平均もしない。友だちには見せない ([`connect.md`](connect.md))                                                                                                                                                                                                        |

## 食事の気持ち

食事の詳細から、食事全体にも気持ち (大好き / 好き / ふつう / 合わなかった) を付けられる (2026-11-28、作り手の判断)。コースやおまかせのように、1 品ずつより、食事全体で覚えておきたいときのため。

- ホームでは聞かない。付けなくてよい
- 品の気持ちとは別に持つ。品のランキングには使わない
- 食事どうしを並べるランキングは、今は作らない

## ランキング

種類ごとの自分のランキング。気持ちの順に並び、同じ気持ちの中の順番は、決めたい人だけが決める。

```
ラーメン                          [比べる]
大好き      1 中華そば · 青葉
好き        1 塩 · らーめん 凪
            ・ 特製醤油 · 麺屋 ひかり   (まだ比べていない)
ふつう      ・ 味噌 · 麺処 さわ
合わなかった ・ つけ麺 · 環
まだ        ・ 11/20 · 中華 宝来        (気持ちがまだ)
```

| 項目               | 決まり                                                                                                                                             |
| ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| 並び               | 「大好き → 好き → ふつう → 合わなかった → まだ (気持ちのない品)」の順                                                                              |
| 同じ気持ちの中の順 | 比べて順番が決まった品は番号で、まだ比べていない品は新しい順で並べる                                                                               |
| 載る品             | 店が決まった記録と、家の記録 ([`recording.md`](recording.md) の「場所」)。「その他」の品は載せない ([`kinds.md`](kinds.md))                        |
| 入口               | 記録のタブを種類で絞ったときだけ、一覧の上にその種類のランキングの入口を出す。その種類の品が 2 つ以上になってから出す ([`history.md`](history.md)) |
| 気持ちを付け直す   | その品は新しい気持ちの段に移り、その段の中では、まだ比べていない品になる                                                                           |
| 手で並べ替える     | 同じ気持ちの中で、手で並べ替えられる。好みが変わったときや、答えを間違えたときのため                                                               |

## 自分から比べる (2 択)

ランキングの画面の「比べる」から始める。ホームでは聞かない。

| 項目         | 決まり                                                                                                                                                                                                                                                                                    |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 比べる範囲   | 同じ気持ちの中だけ。まだ比べていない品を、すでに順番が決まった品の中に挿し込む                                                                                                                                                                                                            |
| 答え方       | 2 つのどちらかをタップする。比べにくいときは「比べられない」を押す                                                                                                                                                                                                                        |
| 比べられない | 種類が同じでも比べにくい組み合わせ (赤ワインと白、立ち食い寿司とおまかせ、手作りの品と店の品など) があるため。押したら、その組み合わせは二度と聞かず、その場で別の相手に替える。答えた数には数えない。ほかに相手がいなければ、その品はまだ比べていないまま残る (2026-11-28、作り手の判断) |
| 相手         | 自分の記録だけ。3 段の真ん中の「種類」(ラーメン、日本酒など) どうし。AI が付けた細かい種類 (赤、白など) が同じ品を先に選ぶ (下の「順位の決め方」)                                                                                                                                         |
| やめる       | いつでもやめられる。途中までの答えは残る                                                                                                                                                                                                                                                  |

### 順位の決め方

比べた答えを使って、まだ比べていない品を、同じ気持ちの中の順番に二分で挿し込む (Beli と同じ型)。1 問答えるたびに、入りうる順位の幅が半分になる。

```
「好き」のラーメン 7 杯 (好きな順)
1 A   2 B   3 C   4 D   5 E   6 F   7 G

新しい H を入れる
1 問目: H と D (真ん中)  → H が好き → H は 1〜4 位のどこか
2 問目: H と B           → B が好き → H は 3〜4 位
3 問目: H と C           → H が好き → H は 3 位に決まる
```

- 順位が決まるまでの問いの数は、同じ気持ちの品の数で決まる。8 品なら 3 問、16 品なら 4 問、32 品なら 5 問
- 順位は答えた範囲で決まる。品どうしの差を点数で持たない
- 相手は、入りうる幅の真ん中の品にする。ただし、真ん中の品と細かい種類 (赤、白など) が違うときや、「比べられない」とした組み合わせのときは、幅の中で真ん中に近い、細かい種類が同じ品にする。細かい種類が分からない品は、種類が同じなら相手にする。幅がちょうど半分にならない問いも出るが、答えやすさを優先する (2026-11-28)
- 途中でやめた品は、「3〜4 位」のように幅で見せる

### 採らない方式

| 方式                                          | 採らない理由                                                                                                                                    |
| --------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| ホームで 2 択を聞く (前の案)                  | 答えなくても流れ、1 問だけで、品は 1 日に何品もあるので、答えが集まらず順位が育たない。気持ちの問いと 1 枠を取り合う (2026-11-28、作り手の判断) |
| 気持ちを点数にする (Beli の 0〜10 点)         | 点の意味が分かりにくい (「6.2 とは何か」という声がある)。点数はつけない                                                                         |
| 2 択だけで好みを知る (前の案)                 | 苦手、好みの強さ、相手のいない品の気持ちが残らない                                                                                              |
| 保存した直後に聞く (前の案)                   | 食べる前に聞くことになる。保存のたびに画面が 1 枚増え、記録の手数が増える                                                                       |
| 勝ち負けから見えない点数を推定する (Elo など) | 答えるたびにほかの品の順位まで揺れる。なぜその順位なのかを説明しにくく、自分の好きな順を作る用途に合わない                                      |
| 順位の幅がいちばん広い品から聞く (前の案)     | 数週間前の品が出て、味を覚えていないことがある                                                                                                  |

## 入れないもの

| もの                           | 理由                                                                                                    |
| ------------------------------ | ------------------------------------------------------------------------------------------------------- |
| 店に付ける「また行きたい」の印 | 同じ店に何度も行くことはあまりない (作り手の声。[`taste.md`](taste.md))。気持ちと、好みのことばで足りる |

## PHASE 1 で確かめること

PHASE 1 の合否は作り手の手応えで決める ([`../concept.md`](../concept.md))。ここに挙げる数字は、アプリが自動で残せるものだけにし、見返しの材料にする。

- 気持ちを出した数と、答えた率。「次に開いたとき」に聞くので、記録するときしか開かない人には問いが遅れる。その遅れが答えた率を下げていないかを見る
- 食べてから答えるまでの日数。「7 日以内」の線が合っているかを、答えた率と合わせて見直す
- 自分から比べた回数と、「比べられない」を押した率

## 参考にした事例

| 事例              | 型                                                                                                                                                                                                                         |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Beli              | 店に行ったあとに記録し、「好き / 普通 / 好きでない」を選んでから 2 択を数問続け、0〜10 の点を出す。「比べにくい」で飛ばせる。比べにくいもの同士を比べさせられる、点の意味が分からない、という声がある                      |
| Netflix           | 2017 年に 5 つ星をやめて親指 (上 / 下) にし、試験で評価の操作が 200% 増えた。星は「平均点」と誤解されていた。2022 年に「大好き」を足し、今は 3 段 (Not for me / I like this / Love this! = 私には合わない / 好き / 大好き) |
| Letterboxd        | 星とは別に「いいね」があり、利用者は「星は出来、いいねは好き」と使い分けている                                                                                                                                             |
| 研究 (苦手の信号) | 苦手を無視すると推薦が鈍る。苦手の信号は、好きの記録がまだない最初の時期に特に効く。YouTube で低評価を学習に入れると、低評価の率が 2.44% 減った                                                                            |
| 研究 (2 択と段)   | 2 択は 1 回の誤差が小さく速いが、1 回で得られる情報は少ない。2 択と点数を組み合わせると、どちらか単独より良い                                                                                                              |
