# つながる (UX)

> **状態: 合意 (2026-11-26)**。ワイヤーフレームまで見て、この形で進める。「案」はもうない。スタンプの種類、運営からのお知らせの中身などは「決めていないこと」に残す。アカウントと最初のチュートリアルは [`onboarding.md`](onboarding.md) で決めた。
>
> ワイヤーフレーム: [`connect-flow.html`](connect-flow.html)。ブラウザで開く。

## 目的

記録を気の知れた人に見せ、反応を受けられるようにする。記録を続ける後押しにする。一人で使っても成り立つことが前提で、つながりはその上に乗せる ([`../concept.md`](../concept.md))。

## 背景 (作り手の声)

- 続いているのはインスタのストーリーと Locket。気軽に上げられ、上げたあと知り合いからスタンプやいいね、ときどき「どこ?」「おいしそう」の DM が届いて話が広がる。他の人の投稿も見られる
- 見せる相手は、身内や知り合いなど気の知れた人。不特定多数は前提にしないが、気の知れた人には見せる前提でもいい
- 今の SNS への不満: 写真を後から見返しづらい、食べた場所が分からない、分類できない

詳しくは [`achievements.md`](achievements.md) の背景。

## 誰とつながるか

お互いに承認した友だちとだけつながる。

```
A さん ──申請──▶ B さん
       ◀──承認──
→ 友だちになってはじめて、お互いの記録が見える
```

| 項目               | 決まり                                                                                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| つながり方         | 申請して、相手が承認したら友だちになる (QR コードで行う。下の「友だちの見つけ方」)                                                                                          |
| 全体公開・フォロー | 最初の版に入れない。不特定多数を前提にしないため。知らない人の投稿が流れてくると、App Store の審査ガイドライン 1.2 が求める通報・ブロックへの対応 (運営の見回り) も重くなる |
| 公開範囲           | 自分だけ / 友だち の 2 つ                                                                                                                                                   |

## 友だちの見つけ方

まずは QR コードだけにする。会っているときに、その場で読み取ってもらう。

```
友だちのタブ (友だちがいないとき)
┌───────────────────────────┐
│ 友だちに食事をシェアして、         │
│ スタンプやメッセージを受け取れます │
│ [ QR コードを見せる ] [ 読み取る ] │
└───────────────────────────┘

読み取った側
┌───────────────────────────┐
│ はるか さんと友だちになりますか?   │
│ [ 友だちになる ]                   │
└───────────────────────────┘
→ その場で友だちになる。はるかには通知が届く
```

| 項目                | 決まり                                                                                                                                         |
| ------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- |
| 申請と承認          | QR コードを見せることが申請、読み取った側が「友だちになる」を押すことが承認。承認待ちは残らない                                                |
| QR コードの使い回し | 見せるたびに変わり、短い時間で切れる。スクリーンショットが広まって、知らない人が入ってこないようにするため                                     |
| 入れていない相手    | スマホのカメラで読むと、アプリを入れる案内に進む。入れたあと、もう一度読み取ってもらう                                                         |
| 友だちがいないとき  | 友だちのタブに、QR コードを見せる・読み取るの入り口を出す                                                                                      |
| 名前                | 友だちの機能をはじめて使うとき (QR コードを見せる・読み取るとき) に決める。アカウントを作るときには聞かない ([`onboarding.md`](onboarding.md)) |

- 招待リンクと、外への共有 (LINE で店を勧めるなど) は、最初の版 (MVP) には入れない (作り手の判断。2026-11-27 のレビューで挙がったが、変えない)。あとから足せる
- ID で探す機能は作らない。知らない人から申請が届く入り口になるため
- 連絡先から探す機能も作らない。電話帳を預かることになるため

## 何を見せるか

友だちに見えるのは、写真とメモだけ。種類と場所 (店名・地域名・家) は見せない。

- 誰の記録か、いつの記録か (日付) は、並べるために出す

## シェアするかどうか

食事単位で、確認カードと食事の詳細で選ぶ。既定は設定で選べる (自分だけ / 友だち)。最初は「自分だけ」(2026-11-28、作り手の判断。以前は「友だち」)。

```
確認カード
┌───────────────────────────┐
│ [写真]                             │
│ [ラーメン ▾]                       │
│ 場所    麺屋 ひかり ▾              │
│ シェア  友だち ▾                   │  ← 友だちがいるときだけ出す。食事ごと
│ メモ (任意)                        │
│ [ 残す ]                           │
└───────────────────────────┘
```

| 項目         | 決まり                                                                                                                                                                        |
| ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 選ぶ場所     | 確認カードの「シェア」の欄。友だちが 1 人もいないあいだは出さず、一人で使うときの画面は変わらない                                                                             |
| 単位         | 食事。どの品のカードで変えても、同じ食事の品すべてに効く                                                                                                                      |
| 既定         | 既定は設定で選べる (自分だけ / 友だち)。最初は「自分だけ」(2026-11-28、作り手の判断。以前は「友だち」)。設定は友だちの機能を使い始めてから出す ([`settings.md`](settings.md)) |
| 保存したあと | 食事の詳細で変えられる (場所と同じく食事ごと)。「自分だけ」にすれば、友だちからは見えなくなる                                                                                 |

- 既定を設定で選べるようにし、最初を「自分だけ」にしたのは、撮ったら残る形では写真を見返さずに残す食事が大半になり、口にするものすべてを残せるので日常の食事も増えるため。見ていない写真が友だちに出ないようにする。見せたい人は、設定で既定を「友だち」にできる
- 以前は既定を「友だち」にしていた (気の知れた人には見せる前提でもいい、という声に合わせ、見せるたびに 1 タップ増えるのを避けるため)
- シェアする食事でも、最短 2 タップ (＋ → シャッター) は変わらない。既定を「友だち」にしていれば、そのまま友だちに見える
- うっかりシェアしてしまうことはある。相手は承認し合った友だちだけで、あとから戻せるので受け入れる
- 友だちができる前の食事は、既定の「自分だけ」のまま残る。最初の友だちに、過去の記録がまとめて見えることはない

## 友だちの記録を見る場所

友だち専用のタブにする。

| 項目                   | 決まり                                                                                                                      |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| 置き方                 | 友だちのタブを 1 つ設ける。ホームには、友だちの新しい食事があるときだけ 1 行の動線を置く ([`navigation.md`](navigation.md)) |
| 並び                   | 友だちがシェアした食事を、新しい順に並べる。写真とメモを見せる                                                              |
| 食事をタップ           | 友だちの食事の詳細を開く                                                                                                    |
| 不特定多数に広げるとき | 全体公開を入れることになっても、このタブの中で切り替える。ほかの画面には持ち込まない                                        |

- 友だちの機能は、まずはお試しのおまけとして入れる。記録やホームなどのメインの機能には混ぜず、1 つのタブに閉じる
- うまくいけば、ホームなどメインの機能に少しずつ出していく。それは構わない
- 友だちの記録をホームの主役にする案は、お試しの機能をメインの画面に混ぜないため、採らなかった。ただし、メインにならない程度に、ホームから友だちのタブへの動線は置いてよい (作り手の判断)

## 友だちの食事の詳細と友だちの一覧

| 画面               | 決まり                                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------------------------- |
| 友だちの食事の詳細 | 品ごとに写真とメモを並べる。下にスタンプと「メッセージを送る」を置く。右上の … から通報できる                  |
| 友だちの一覧       | 友だちのタブの見出しの「友だち N 人」から開く。友だちをやめる・ブロックと、QR コードで友だちを足すことができる |

## 反応

スタンプとメッセージを送れる。やりとりは友だちごとに 1 つのスレッドで続く。

```
友だちのタブ
┌───────────────────────────┐
│ 友だち             メッセージ 2   │  ← 新しいメッセージがあると数が出る
│ はるか · 11/26                     │
│ ▢ ▢ ▢   獺祭 純米大吟醸 45         │  ← 写真とメモだけ
│ けんた · 11/25                     │
│ ▢        (メモなし)                │
└───────────────────────────┘
        ↓ メッセージ
スレッドの一覧 (友だちごとに 1 つ)
│ まい    どこのお店?                │
│ けんた  ◯ を送りました             │
        ↓ タップ
まいとのスレッド
│ ┌ 11/26 の食事 ▢▢ ┐                │  ← どの食事への反応か、写真で分かる
│ まい   どこのお店?                 │
│ 自分   恵比寿の鮨 はやし           │
│ ┌ 11/20 の食事 ▢ ┐                 │
│ まい   ◯                           │  ← スタンプもここに流れる
│ [ メッセージ               ]       │
```

| 項目       | 決まり                                                                                                   |
| ---------- | -------------------------------------------------------------------------------------------------------- |
| スタンプ   | 友だちの食事に、数種類から 1 つ送れる                                                                    |
| メッセージ | 友だちの食事から送ると、その人とのスレッドに、食事の写真を添えて流れる。スタンプも同じように流れる       |
| スレッド   | 友だちごとに 1 つ。どの食事への反応かは、添えた写真で分かる。中では食事と関係なく、自由に送れる          |
| 見える人   | 当事者の 2 人だけ。ほかの友だちには、件数も中身も見せない                                                |
| 置き場所   | メッセージの一覧は、友だちのタブの中に置く。お試しの機能を 1 つのタブに閉じるため                        |
| 見返し     | 自分の食事の詳細に、その食事に届いたスタンプとメッセージを並べる。タップすると、その人とのスレッドに移る |

- 返信できるようにする。食事ごとのやりとりにはせず、インスタの DM と同じく友だちごとの 1 スレッドにする (作り手の判断)
- 場所は見せないので、「どこ?」はスレッドで聞いて答える
- みんなが見るコメント欄は作らない。友だちの友だちとは知り合いとは限らず、知らない人の言葉が見えてしまうため
- 1 対 1 のスレッドでスタンプとメッセージを届けるので、電気通信事業の届出を出す (作り手の判断。確かめることは [`../open-questions.md`](../open-questions.md))

## 知らせ方

プッシュ通知で知らせる。どの通知も、種類ごとに止められる。

```
ロック画面
┌───────────────────────────┐
│ HINAMI                             │
│ まい: どこのお店?                  │
└───────────────────────────┘

タブバー
[ホーム] [記録] [実績] [友だち ②]   ← 自分あての未読の数
```

| 項目               | 決まり                                                                                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 友だちになった     | QR コードを見せた側に、プッシュ通知を送る                                                                                                                                   |
| 自分あての反応     | スタンプやメッセージが届いたら、プッシュ通知を送る                                                                                                                          |
| 友だちの新しい食事 | 友だちが食事をシェアしたら、プッシュ通知を送る。1 回の食事で 1 回だけ。品が増えても送り直さない                                                                             |
| 止める             | 通知は種類ごとに、設定で止められる。既定はどれも送る。運営からのお知らせが宣伝を含むなら、受け取る同意を別に取り、既定はオフ ([`onboarding.md`](onboarding.md))             |
| タブの数           | 友だちのタブのアイコンに、自分あての未読の数を出す                                                                                                                          |
| 許可を求めるとき   | 最初のチュートリアルで求める。友だちの通知のほかに、運営からのお知らせもあるため。友だちを足すときに回すと、友だちの機能を使わない人にお知らせが届かなくなる (作り手の判断) |

- 運営からのお知らせも送る。中身は未決。宣伝を含むなら、App Store の審査ガイドライン 4.5.4 により、OS の通知の許可とは別に、アプリの中で受け取ることへの同意をもらう
- 比べるや実績でプッシュ通知を使わないのは、どちらもアプリを開いているときに起きる出来事だから。通知そのものを避ける方針ではない

## 友だちをやめる・ブロック・通報

App Store の審査ガイドライン 1.2 は、人が投稿できるアプリに、投稿前に不適切なものを弾く仕組み、通報の仕組みと運営のすばやい対応、迷惑な人のブロック、運営の連絡先を求めている。友だちだけのつながりでも満たす。

```
友だちの一覧
│ はるか                        … │ → [友だちをやめる] [ブロック]

友だちの食事 / メッセージ
│ ▢ ▢   獺祭 純米大吟醸 45      … │ → [通報]
```

| 項目               | 決まり                                                                                                                                           |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ |
| 友だちをやめる     | お互いの食事とスレッドが見えなくなる。相手には知らせない                                                                                         |
| ブロック           | 友だちをやめたうえで、その人の QR コードで二度と友だちになれなくする。相手には知らせない。設定から解除できる ([`settings.md`](settings.md))      |
| 通報               | 友だちの食事とメッセージから通報できる。通報したものは自分から見えなくなり、運営に届く。運営は中身を確かめて、消す、利用を止めるなどの対応をする |
| 連絡先             | アプリの中に、運営への問い合わせ先を載せる                                                                                                       |
| 投稿前に弾く仕組み | メッセージの言葉や写真をどう判定するかは、技術と一緒に決める ([`../open-questions.md`](../open-questions.md))                                    |

## 参考にした事例

| 事例      | 型                                                                                     |
| --------- | -------------------------------------------------------------------------------------- |
| Locket    | 承認し合った友だちとだけつながる                                                       |
| Instagram | ストーリーへの反応や返信が、その人との DM に、どのストーリーへのものか分かる形で流れる |

## 決めていないこと

- スタンプの種類
- 投稿前に不適切なものを弾く仕組みの中身
- 運営からのお知らせの中身 (宣伝を含むか)
