# つながる (UX)

> **状態: 検討中 (2026-11-26)**。誰とつながるか、記録ごとに見せるかどうかの選び方、友だちの記録を見る場所まで決めた。

## 目的

記録を気の知れた人に見せ、反応を受けられるようにする。記録を続ける後押しにする。一人で使っても成り立つことが前提で、つながりはその上に乗せる ([`../concept.md`](../concept.md))。

## 背景 (作り手の声)

- 続いているのはインスタのストーリーと Locket。気軽に上げられ、上げたあと知り合いからスタンプやいいね、ときどき「どこ?」「おいしそう」の DM が届いて話が広がる。他の人の投稿も見られる
- 見せる相手は、身内や知り合いなど気の知れた人。不特定多数は前提にしないが、気の知れた人には見せる前提でもいい
- 今の SNS への不満: 写真を後から見返しづらい、食べた場所が分からない、分類できない

詳しくは [`achievements.md`](achievements.md) の背景。

## 誰とつながるか

お互いに承認した友だちとだけつながる。

```
A さん ──申請──▶ B さん
       ◀──承認──
→ 友だちになってはじめて、お互いの記録が見える
```

| 項目               | 決まり                                                                                                                                                                      |
| ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| つながり方         | 申請して、相手が承認したら友だちになる                                                                                                                                      |
| 全体公開・フォロー | 最初の版に入れない。不特定多数を前提にしないため。知らない人の投稿が流れてくると、App Store の審査ガイドライン 1.2 が求める通報・ブロックへの対応 (運営の見回り) も重くなる |
| 公開範囲           | 自分だけ / 友だち の 2 つ                                                                                                                                                   |

- HINAMI の記録には場所と種類が付くので、「それどこ?」には記録そのものが答えられる。今の SNS の不満を埋められる

## 記録ごとに見せるかどうか

確認カードで選ぶ。既定は「友だち」。

```
確認カード
┌───────────────────────────┐
│ [写真]                             │
│ [ラーメン ▾]                       │
│ 場所    麺屋 ひかり ▾              │
│ 見せる  友だち ▾                   │  ← 友だちがいるときだけ出す
│ メモ (任意)                        │
│ [ 残す ]                           │
└───────────────────────────┘
```

| 項目         | 決まり                                                                                            |
| ------------ | ------------------------------------------------------------------------------------------------- |
| 選ぶ場所     | 確認カードの「見せる」の欄。友だちが 1 人もいないあいだは出さず、一人で使うときの画面は変わらない |
| 既定         | 友だち。見せたくない記録だけ「自分だけ」に切り替える                                              |
| 同じ食事     | 選んだものを、同じ食事の次の品に引き継ぐ (場所と同じ)                                             |
| 保存したあと | 食事の詳細で変えられる。「自分だけ」にすれば、友だちからは見えなくなる                            |

- 既定を「友だち」にするのは、気の知れた人には見せる前提でもいい、という声に合わせるため。ストーリーや Locket が続くのは上げるのが軽いからで、既定を「自分だけ」にすると、見せるたびに 1 タップ増え、友だちの記録も流れてこなくなる
- 見せる記録でも、最短 3 タップは変わらない
- うっかり見せてしまうことはある。相手は承認し合った友だちだけで、あとから戻せるので受け入れる

## 友だちの記録を見る場所

友だち専用のタブにする。

| 項目                   | 決まり                                                                                 |
| ---------------------- | -------------------------------------------------------------------------------------- |
| 置き方                 | 友だちのタブを 1 つ設ける。ホームには出さない                                          |
| 並び                   | 友だちの記録を、新しい順に食事単位で並べる。履歴の一覧と同じ形にし、場所と種類も見せる |
| 食事をタップ           | 友だちの食事の詳細を開く                                                               |
| 不特定多数に広げるとき | 全体公開を入れることになっても、このタブの中で切り替える。ほかの画面には持ち込まない   |

- 友だちの機能は、まずはお試しのおまけとして入れる。記録や履歴などのメインの機能には混ぜず、1 つのタブに閉じる
- うまくいけば、ホームなどメインの機能に少しずつ出していく。それは構わない
- ホームに出す案も考えた (開くたびに友だちの記録が目に入る)。お試しの機能をメインの画面に混ぜないため、採らなかった

## 決めていないこと

- 友だちの見つけ方 (招待リンク、QR コードなど)
- 友だちのタブの中身 (友だちがいないときに何を出すか、友だちの食事の詳細)
- 反応の種類
- 通報とブロック (App Store の審査ガイドライン 1.2)
