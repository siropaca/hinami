# 長く使うほど返るもの (UX)

> **状態: 方針を決めた (2026-11-28)**。3 つを時期で分けて返す (作り手の判断)。見た目、頁の数、しきい値の数は、作りながら決める。根拠の調査とレビューは下の「参考にした事例と研究」。
>
> ワイヤーフレーム (画面遷移図): [`memory-flow.html`](memory-flow.html)。ブラウザで開く。

## 目的

実績の見返りは最初の数週に厚く、2〜3 か月目から減る ([`../reviews/2026-11-27-review.md`](../reviews/2026-11-27-review.md))。コンセプトの芯の「記憶している」と「育つ」を、半年、1 年、数年と使った人に返す ([`../concept.md`](../concept.md))。

## 時期で分ける 3 つ

| 時期         | もの           | 中身                                                                                                         |
| ------------ | -------------- | ------------------------------------------------------------------------------------------------------------ |
| 数週から     | 前にも         | 前にも記録した品や店に出会うと、前回の時期と気持ち、何度目かを 1 行で出す                                    |
| 3 か月目から | 季節と年の帳面 | 季節や年が終わったら、その期間を「新しく出会った / 戻ってきた / ずっと好き」で、写真と自分の言葉でふりかえる |
| 1 年目から   | 自分の歳時記   | 毎年同じ季節に口にしている、大好きな品を、その季節に入ったら出す                                             |

- 時期で役割を分けるのは、どれか 1 つでは、はじめの数週から数年までを受け持てないため。最初の季節の帳面は、見返りが減る 2〜3 か月目に届く
- どれも通知で押さない。アプリを開いたときにだけ出す
- どれも自分だけ。友だちには見せない ([`connect.md`](connect.md))

## 前にも

```
確認カード / 品の画面
獺祭 純米大吟醸 45
前にも · 2025/3 · 大好き (3 度目)     ← タップで前の記録を開く
```

| 項目                   | 決まり                                                                                                                         |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 出す場所               | 確認カード、品の画面、写真なしで残す画面。名前が入ったときや店が決まったときに出す                                             |
| トーストに出さないこと | 保存のトーストは、残しました・直す・取り消す・実績で混んでいる。撮ったら残る形では、保存の時点で名前が分からないことも多いため |
| 当て方                 | 同じ名前 (読みを含む) の品を先に当てる。名前がないときは、同じ店の同じ種類の品に当てる                                         |
| 出すもの               | いちばん新しい前回の時期と気持ち、何度目か。タップすると前の記録を開く                                                         |
| 前回が合わなかった     | 事実だけを出し、咎める言葉を添えない。好みが変わることもあるため                                                               |

## 季節と年の帳面

| 項目            | 決まり                                                                                                                                                                                                                               |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 区切り          | 季節 (春 3〜5 月、夏 6〜8 月、秋 9〜11 月、冬 12〜2 月) と年                                                                                                                                                                         |
| 届け方          | 期間が終わったあと、次に開いたときにホームのカードで知らせる。前もって予告しない。予告すると、期間に間に合わせる義務になるため                                                                                                       |
| 出す条件        | その期間の記録が足りるときだけ出す (今の案: 季節は 10 件、年は 30 件)。少ない季節は、何も言わずに出さない。使い始めて 1 年に満たない人にも、件数が足りれば年の帳面を出す                                                             |
| 中身            | 「新しく出会った」(はじめての種類や品)、「戻ってきた」(しばらく空いて、また残したもの)、「ずっと好き」(前の期間も大好きや好きだったもの)。大好きな品の写真、行った都道府県、好みのことばの移り変わりを 1 文 ([`taste.md`](taste.md)) |
| 数字            | 控えめにする。件数を大きく出さず、量の多さを称えない。数字だけのまとめは意味が薄く受け取られる。実物の写真と、本人の言葉で見せる                                                                                                     |
| 自分の言葉      | 帳面の頁に、見出しや一言を足せる。長く記録してきた人は、記録をもとに自分の過去を語るため                                                                                                                                             |
| 外す            | 頁ごとに外せる。「思い出に出さない」とした食事・期間・店は出さない                                                                                                                                                                   |
| 触れないこと    | 記録の空白、「合わなかった」の多さ、体調や酒をやめたことの推測、飲む量。酒に戻す方向も出さない                                                                                                                                       |
| 置き場所        | 過去の帳面は、記録のタブから開ける (置き方は作りながら決める)                                                                                                                                                                        |
| 人に見せる 1 枚 | 今は作らない。外への共有は MVP に入れないため ([`connect.md`](connect.md))。外への共有を入れるときに決める                                                                                                                           |

## 自分の歳時記

```
ホーム (1 年以上使った人の、秋に入ったころ)
┌─────────────────────────────┐
│ 去年の秋も、栗のモンブランを          │
│ 大好きと残しています                  │
│ [写真]  2025/10 · 菓子工房 くり   もう出さない │
└─────────────────────────────┘
```

| 項目         | 決まり                                                                                                                                       |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------- |
| 対象         | 1 年以上使った人。去年や一昨年の同じ季節に、大好きか好きを付けた品。毎年同じ季節に残しているもの (新酒、栗の菓子、鮎、おせちなど) を先に出す |
| 出し方       | その季節に入ったら、ホームのカードで出す。1 つの季節に 1〜2 回まで                                                                           |
| 出さない     | 「○年前の今日」は出さない。食の思い出は、日付の単位では関わりが薄く感じられるため。「合わなかった」の品は出さない                            |
| もう出さない | カードに「もう出さない」を置き、理由は聞かない。その品は歳時記に二度と出さない                                                               |

## 思い出に出さない

嫌な思い出 (別れた人との食事、亡くなった人との食事、体調を崩した時期) を、不意に見せないため。

- 食事・期間・店の単位で「思い出に出さない」にできる。前にも、季節と年の帳面、自分の歳時記のどれにも出なくなる
- 記録のタブや検索には残る。消すのではなく、思い出として出さないだけ
- 設定から一覧で見て、戻せる ([`settings.md`](settings.md))
- 人で自動に外すことはしない。写真の顔を見分けた結果を持たないため ([`../data.md`](../data.md))
- 「好みに入れない」([`taste.md`](taste.md)) とは別。好みの材料から外すかと、思い出に出すかは、別のことのため

## 入れないもの

| もの                                      | 理由                                                                             |
| ----------------------------------------- | -------------------------------------------------------------------------------- |
| 見に来た連続日数 (Timehop の型)           | 義務感を生む ([`achievements.md`](achievements.md) の方針)                       |
| 「○年前の今日」                           | 食の思い出は、日付の単位では関わりが薄く感じられる                               |
| 量の上位を称える (いちばん多く飲んだなど) | 量の多い人だけが得をする。飲む量を伸ばす形にもなる                               |
| 好みの移り変わりだけの画面                | 好みのことばと同じものが 2 か所にできる。帳面の 1 文と、好みのことばの中で見せる |

## 参考にした事例と研究

| 事例・研究                     | 分かったこと                                                                                                                           |
| ------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- |
| Facebook「過去のこの日」の研究 | 食べ物の思い出は、時間がたつと自分との関わりが薄く感じられ、共有されにくい。数字だけのまとめは意味が薄い。月や季節のまとめは好評だった |
| Facebook の年のまとめ (2014)   | 亡くなった娘の写真を「いい 1 年」の枠に入れて出し、謝罪に至った                                                                        |
| Apple の写真、Google フォト    | 人・場所・期間を「控えめに表示」や「ブロック」にでき、あとで戻せる                                                                     |
| Apple Music Replay             | 「新しく出会った」「年をまたいで戻ってくる」「また聴くようになった」で見せる                                                           |
| Duolingo の年のまとめ          | 量の上位者が共有の半分超を占めた。学び方の「型」を足し、上位でない人にも共有する理由を作ると、共有の率が上がった                       |
| Strava の年のまとめ            | 2025 年に有料会員だけにし、反発を受けた                                                                                                |
| Letterboxd                     | 記録が 10 件以上ある年だけ、年のページを作る                                                                                           |
| Untappd                        | 同じビールをもう一度記録するとき、前回の評価と、飲んだ回数が見える                                                                     |
| Zhang ほか (2014)              | 人は、日常のありふれた体験を見返す楽しさを過小評価する                                                                                 |
| Elsden ほか (2016)             | 長く記録してきた人は、記録をもとに自分の過去を語っていた。データを増やすより、本人が語るのを支える                                     |
| Epstein ほか (2015、2016)      | 記録は中断と再開を繰り返す。長く使った人は月や年ごとの時系列を好み、うまくいかなかった点を指摘する言い方は嫌われた                     |
