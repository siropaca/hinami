# 0001. モノレポ構成と技術スタック

- 状態: 採用 (web のプロトタイプは、[ADR-0002](0002-phase1-on-testflight.md) で残すかを見直し中)
- 日付: 2026-11-26

## 背景

このリポジトリでは web (プロトタイプ) とネイティブアプリの 2 つを作る。
web はデザインと体験を素早く試すため、ネイティブアプリは本番として使う。
両者で色・書体などのデザイントークンや、記録のドメインモデルを揃えたい。

## 決定

- **ネイティブアプリ: Expo (React Native)**。iOS / Android の両方に対応でき、web と同じ TypeScript で書ける
- **web: Vite + React**。プロトタイプ用途で SSR やサーバー機能は不要なため、最も軽い構成にする
- **モノレポ: pnpm workspace**。`apps/*` にアプリ、`packages/*` に共有ライブラリ (デザイントークン、型、ドメインロジックなど) を置く
- **ツール**: バージョン管理は mise、タスクは Taskfile、lint / format は Biome、git hooks は lefthook

## 結果

- デザイントークンやドメインロジックを `packages/` で一元管理し、web とネイティブで共有できる
- web で試した画面や体験を、ネイティブへ移しやすい
- Swift に比べると iOS 固有 API (カメラ・写真ライブラリ・位置情報) の扱いは Expo のモジュール経由になる。足りない場合は Expo Modules でネイティブコードを足す
